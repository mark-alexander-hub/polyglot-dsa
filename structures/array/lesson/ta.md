**Array** என்பது memory-இல் ஒன்றன் பக்கத்தில் ஒன்றாக அமைந்திருக்கும் boxes-இன் ஒரு row. ஒவ்வொரு
box-க்கும் ஒரு number உண்டு, அதை அதன் **index** என்கிறோம், எண்ணிக்கை `0`-இலிருந்து தொடங்குகிறது.
Index தெரிந்தால், எந்த box-க்கும் நேராகச் செல்லலாம். அதனால்தான் values-இன் list-ஐ வைத்திருக்க array
மிக எளிய, மிக வேகமான வழி.

## அன்றாட வாழ்க்கையில்

Cinema hall-இன் ஒரு row-இல் உள்ள seats-ஐ நினைத்துப் பாருங்கள். Seats தரையில் பொருத்தப்பட்டிருக்கும்,
ஒன்றன் பின் ஒன்றாக, ஒவ்வொரு seat-க்கும் ஒரு number இருக்கும். உங்கள் ticket-இல் seat 7 என்று
இருந்தால், நீங்கள் முதலில் seat 1 முதல் 6 வரை பார்ப்பதில்லை. நேராக seat 7-க்குப் போகிறீர்கள்.

Train-இன் sleeper coach-உம் இப்படித்தான் வேலை செய்கிறது. நீங்கள் எங்கே போக வேண்டும் என்று உங்கள்
berth number சரியாகச் சொல்கிறது, coach-இல் berths-இன் எண்ணிக்கை நிலையானது: coach கட்டி முடித்த பிறகு
யாரும் அதில் இன்னொரு berth சேர்க்க முடியாது.

இந்த எடுத்துக்காட்டுகளில் உள்ள இரண்டு விஷயங்கள் arrays-க்கு முக்கியம்:

- **Number கொண்ட இடங்கள்.** ஒவ்வொரு value-க்கும் நேராக அடையக்கூடிய ஒரு இடம் உண்டு.
- **நிலையான நீளம்.** Row-இல் இடங்களின் எண்ணிக்கை நிலையானது. இன்னும் இடம் வேண்டுமென்றால், புதிய,
  பெரிய row வேண்டும்.

ஒரு வேறுபாடு: cinema seats பொதுவாக 1-இலிருந்து தொடங்கும், ஆனால் code-இல் முதல் box index `0`.

## இது எப்படி வேலை செய்கிறது

ஒரு program array-ஐ உருவாக்கும்போது, computer memory-இல் ஒரு பகுதியை ஒதுக்குகிறது. அதில் எல்லா
boxes-உம் ஒன்றுக்கொன்று அடுத்தடுத்து இருக்கும், ஒவ்வொரு box-இன் size-உம் ஒன்றே. அதனால் எந்த box
எங்கே இருக்கிறது என்பதை ஒரு சிறிய கணக்கிலேயே computer கண்டுபிடித்துவிடுகிறது:

```text
address of box i = address of box 0 + i * size of one box
```

Box `0` address `1000`-இல் தொடங்கி, ஒவ்வொரு box-உம் 4 bytes எடுத்தால், box `3` address
`1000 + 3 * 4 = 1012`-இல் இருக்கும். தேடவும் வேண்டாம், எண்ணவும் வேண்டாம்: அதனால்தான் எந்த box-ஐயும்
படிப்பது உடனே நடக்கிறது.

நாம் நிலையான எண்ணிக்கையில் boxes கொண்ட ஒரு array-ஐ உருவாக்குவோம், அந்த எண்ணிக்கையே அதன்
**capacity**. கூடவே, எத்தனை boxes பயன்பாட்டில் உள்ளன என்று எண்ணும் **size** என்ற இன்னொரு number-ஐ
வைத்திருப்போம். Values எப்போதும் box `0` முதல் `size - 1` வரை, இடையில் இடைவெளி இல்லாமல் இருக்கும்.

> **ஏன் நாமே உருவாக்க வேண்டும்?** Python `list`, C++ `std::vector`, Java `ArrayList`,
> JavaScript array ஆகிய எல்லாமே உள்ளே arrays தான், உங்களுக்காகத் தானாக வளர்கின்றன. (PHP array
> உண்மையில் ஒரு ordered map; PHP-இல் நிலையான size உள்ள boxes row-க்கு மிக நெருக்கமானது
> `SplFixedArray`.) ஒரு fixed
> array-ஐ நீங்களே உருவாக்கினால், அவை திரைக்குப் பின்னால் செய்யும் நகர்த்தும் வேலையைப் பார்க்கலாம்,
> சில operations ஏன் வேகமானவை, சில ஏன் மெதுவானவை என்றும் புரியும்.

## Operations

### get: ஒரு index-இல் உள்ள value-ஐப் படிப்பது

1. Index `0`-ஐ விடக் குறைவாக இருந்தால், அல்லது `size`-ஐ விடச் சிறியதாக இல்லையென்றால், அங்கே value
   இல்லை. அதனால் **index out of range** error கொடுத்து நிறுத்துகிறோம்.
2. இல்லையென்றால், அந்த box-இல் உள்ள value-ஐ return செய்யுங்கள். Loop தேவையில்லை.

### insert: ஒரு index-இல் value-ஐ வைப்பது

Values அடுத்தடுத்தே இருக்க வேண்டும். அதனால் `index`-இல் இடம் உருவாக்க, `index` முதல் அதற்குப் பின்
உள்ள ஒவ்வொரு value-உம் ஒரு box வலப்பக்கம் நகர்கிறது.

1. `size`-உம் `capacity`-உம் சமமாக இருந்தால், எல்லா boxes-உம் நிரம்பியுள்ளன, அதனால் **array is
   full** கொடுத்து நிறுத்துகிறோம்.
2. Index `0` முதல் `size` வரை எதுவாகவும் இருக்கலாம். `size`-இல் insert செய்வது என்றால் கடைசியில்
   சேர்ப்பது; அப்போது எதையும் நகர்த்த வேண்டியதில்லை.
3. **கடைசியிலிருந்து** தொடங்கி, `index`-ஐ அடையும் வரை ஒவ்வொரு value-ஐயும் ஒரு box வலப்பக்கம்
   நகர்த்துங்கள்.
4. புதிய value-ஐ `index`-இல் வைத்து, `size`-உடன் ஒன்றைச் சேருங்கள்.

<!-- code: insert -->

ஏன் கடைசியிலிருந்து தொடங்க வேண்டும்? முதலில் `index`-இல் உள்ள value-ஐ நகர்த்தினால், பக்கத்து value
நகர்வதற்கு முன்பே அதன் மேல் எழுதிவிடும். வலமிருந்து இடமாகச் சென்றால், நீங்கள் எழுதும் ஒவ்வொரு
box-இன் value-உம் ஏற்கெனவே copy ஆகியிருக்கும்.

### remove: ஒரு index-இல் உள்ள value-ஐ நீக்குவது

1. `get` செய்வது போலவே index-ஐச் சரிபாருங்கள்.
2. `index`-இல் உள்ள value-ஐ நினைவில் வையுங்கள்.
3. இடைவெளியை மூடுங்கள்: அதற்குப் பின் உள்ள ஒவ்வொரு value-ஐயும் ஒரு box இடப்பக்கம் நகர்த்துங்கள்.
4. `size`-இலிருந்து ஒன்றைக் கழித்து, நினைவில் வைத்த value-ஐ return செய்யுங்கள்.

<!-- code: remove -->

கடைசி box-இல் இன்னும் ஒரு value-இன் பழைய copy இருக்கும், ஆனால் அது இப்போது `size`-க்கு வெளியே
இருப்பதால் array-இன் பகுதி அல்ல. மேலே உள்ள playground-இல் இந்தப் பழைய copies மங்கலாகத் தெரியும்.

### search: ஒரு value எங்கே இருக்கிறது என்று தேடுவது

ஒவ்வொரு box-இலும் என்ன இருக்கிறது என்று array-க்குத் தெரியும், ஆனால் ஒரு குறிப்பிட்ட value எங்கே
இருக்கிறது என்று தெரியாது. அதனால் `search` index `0`-இலிருந்து தொடங்கி boxes-ஐ ஒவ்வொன்றாகப் பார்த்து,
முதலில் பொருந்தும் index-ஐ return செய்கிறது; value இல்லையென்றால் `-1`. இதை **linear search**
என்கிறோம்.

## இது எவ்வளவு வேகமானது?

| Operation | இது என்ன செய்கிறது | Time |
|---|---|---|
| `get` | ஒரு index-இன் box-ஐப் படிப்பது | `O(1)` |
| கடைசியில் `insert` | box `size`-இல் எழுதுவது, எதுவும் நகராது | `O(1)` |
| ஒரு index-இல் `insert` | அதிகபட்சம் `size` values-ஐ வலப்பக்கம் நகர்த்துவது | `O(n)` |
| கடைசியிலிருந்து `remove` | எதுவும் நகராது | `O(1)` |
| ஒரு index-இலிருந்து `remove` | அதிகபட்சம் `size` values-ஐ இடப்பக்கம் நகர்த்துவது | `O(n)` |
| `search` | boxes-ஐ ஒவ்வொன்றாகப் பார்ப்பது | `O(n)` |

இங்கே `n` என்பது values-இன் எண்ணிக்கை. Index `0`-இல் insert செய்வதுதான் மிக மெதுவானது, ஏனென்றால்
ஒவ்வொரு value-உம் நகர வேண்டும். `n` values-க்கு இடம் உள்ள array-க்கு `O(n)` memory தேவை, அதன்
பெரும்பாலான boxes காலியாக இருந்தாலும் கூட.

## பொதுவான தவறுகள்

- **1-இலிருந்து எண்ணுவது.** முதல் box index `0`, கடைசி box `size - 1`. Index `size` ஒரு படி
  தாண்டிவிடுகிறது.
- **Size-ஐயும் capacity-ஐயும் குழப்பிக்கொள்வது.** `capacity` என்பது எத்தனை boxes உள்ளன; `size`
  என்பது அவற்றில் எத்தனையில் உண்மையான values உள்ளன.
- **தவறான திசையில் நகர்த்துவது.** `insert`-க்கு கடைசியிலிருந்து index நோக்கி copy செய்யுங்கள்.
  `remove`-க்கு index-இலிருந்து கடைசி நோக்கி. மாற்றிச் செய்தால், values நகர்வதற்கு முன்பே
  அழிந்துவிடும்.
- **Size-ஐ மாற்ற மறப்பது.** ஒவ்வொரு insert-உம் ஒன்றைக் கூட்டுகிறது, ஒவ்வொரு remove-உம் ஒன்றைக்
  குறைக்கிறது.
- **மீண்டும் மீண்டும் முன்பக்கத்தில் insert செய்வது.** ஒவ்வொரு insert-உம் எல்லாவற்றையும்
  நகர்த்துகிறது, அதனால் இப்படி `n` values சேர்க்க `O(n²)` time ஆகும். முடிந்தபோதெல்லாம் கடைசியில்
  சேருங்கள்.

## இது எங்கே பயன்படுகிறது?

- **கிட்டத்தட்ட எல்லா இடத்திலும்.** Lists, vectors, ArrayLists, JavaScript arrays எல்லாமே arrays
  மேல்தான் கட்டப்பட்டுள்ளன.
- **Images.** ஒரு photo என்பது pixel colours-இன் ஒரு பெரிய array.
- **Class register-இல் marks.** ஒவ்வொரு roll number-க்கும் ஒரு mark: roll number-தான் index.
- **Lookup tables**, எடுத்துக்காட்டாக ஒவ்வொரு மாதத்திலும் உள்ள நாட்களின் எண்ணிக்கை; இங்கே index
  உடனே பதில் தருகிறது.
- **மற்ற structures.** இந்த course-இல் வரும் stack-உம் queue-உம் arrays மேல்தான்
  கட்டப்பட்டுள்ளன.

## இவற்றைச் செய்து பாருங்கள்

1. `[3, 9, 4]`-இல் index `1`-இல் `7`-ஐ insert செய்யுங்கள். எந்த values நகர்கின்றன, எந்த வரிசை
   முறையில்? உங்கள் பதிலை playground-இல் சரிபாருங்கள்.
2. Array-இன் மிகப் பெரிய value-ஐ return செய்யும் ஒரு function எழுதுங்கள். அது எத்தனை boxes-ஐப்
   பார்க்க வேண்டும்?
3. Array-ஐ அதே இடத்தில் தலைகீழாக மாற்றும் ஒரு function எழுதுங்கள்: முதல் மற்றும் கடைசி values-ஐ இடம்
   மாற்றுங்கள், பிறகு இரண்டாவது மற்றும் கடைசியிலிருந்து இரண்டாவது, இப்படியே தொடருங்கள்.
4. நிரம்பிய array தன் capacity-ஐ இரண்டு மடங்காக்கும்படி `insert`-ஐ மாற்றுங்கள்: இரண்டு மடங்கு பெரிய
   புதிய array-ஐ உருவாக்கி, ஒவ்வொரு value-ஐயும் அதில் copy செய்து, பிறகு insert செய்யுங்கள். Python
   lists-உம் C++ vectors-உம் இப்படித்தான் வளர்கின்றன.
