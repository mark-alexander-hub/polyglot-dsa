**Array** ಎಂದರೆ memory ಯಲ್ಲಿ ಒಂದರ ಪಕ್ಕ ಒಂದರಂತೆ ಇರುವ boxes ನ ಒಂದು ಸಾಲು. ಪ್ರತಿ box ಗೆ ಒಂದು
number ಇರುತ್ತದೆ, ಅದನ್ನು ಅದರ **index** ಎನ್ನುತ್ತಾರೆ, ಮತ್ತು ಎಣಿಕೆ `0` ಯಿಂದ ಶುರುವಾಗುತ್ತದೆ. Index
ಗೊತ್ತಿದ್ದರೆ ನೀವು ಯಾವ box ಗಾದರೂ ನೇರವಾಗಿ ಹೋಗಬಹುದು. ಅದಕ್ಕಾಗಿಯೇ values ನ list ಇಡಲು array ಅತ್ಯಂತ
ಸರಳ ಮತ್ತು ಅತ್ಯಂತ ವೇಗದ ದಾರಿ.

## ನಿಜ ಜೀವನದಲ್ಲಿ

Cinema hall ನ ಒಂದು row ನಲ್ಲಿರುವ seats ಬಗ್ಗೆ ಯೋಚಿಸಿ. Seats ನೆಲಕ್ಕೆ ಜೋಡಿಸಲ್ಪಟ್ಟಿರುತ್ತವೆ, ಒಂದಾದ ನಂತರ
ಒಂದು, ಮತ್ತು ಪ್ರತಿ seat ಗೆ ಒಂದು number ಇರುತ್ತದೆ. ನಿಮ್ಮ ticket ನಲ್ಲಿ seat 7 ಎಂದು ಇದ್ದರೆ, ನೀವು
ಮೊದಲು seat 1 ರಿಂದ 6 ರವರೆಗೆ ನೋಡುವುದಿಲ್ಲ. ನೇರವಾಗಿ seat 7 ಗೆ ಹೋಗುತ್ತೀರಿ.

Train ನ sleeper coach ಕೂಡ ಹೀಗೆಯೇ ಕೆಲಸ ಮಾಡುತ್ತದೆ. ನೀವು ಎಲ್ಲಿಗೆ ಹೋಗಬೇಕು ಎಂದು ನಿಮ್ಮ berth number
ನಿಖರವಾಗಿ ಹೇಳುತ್ತದೆ, ಮತ್ತು coach ನಲ್ಲಿ berths ನ ಸಂಖ್ಯೆ ನಿಗದಿತವಾಗಿರುತ್ತದೆ: coach ತಯಾರಾದ ನಂತರ ಯಾರೂ
ಅದಕ್ಕೆ ಇನ್ನೊಂದು berth ಸೇರಿಸಲು ಸಾಧ್ಯವಿಲ್ಲ.

ಈ ಉದಾಹರಣೆಗಳಲ್ಲಿನ ಎರಡು ವಿಷಯಗಳು arrays ಗೆ ಮುಖ್ಯ:

- **Number ಇರುವ ಸ್ಥಾನಗಳು.** ಪ್ರತಿ value ಗೂ ನೀವು ನೇರವಾಗಿ ತಲುಪಬಹುದಾದ ಒಂದು ಸ್ಥಾನ ಇದೆ.
- **ನಿಗದಿತ ಉದ್ದ.** Row ನಲ್ಲಿ ಸ್ಥಾನಗಳ ಸಂಖ್ಯೆ ನಿಗದಿತ. ಇನ್ನಷ್ಟು ಬೇಕಾದರೆ, ಹೊಸ ಮತ್ತು ದೊಡ್ಡ row ಬೇಕು.

ಒಂದು ವ್ಯತ್ಯಾಸ: cinema seats ಸಾಮಾನ್ಯವಾಗಿ 1 ರಿಂದ ಶುರುವಾಗುತ್ತವೆ, ಆದರೆ code ನಲ್ಲಿ ಮೊದಲ box index
`0`.

## ಇದು ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ

ಒಂದು program array ರಚಿಸಿದಾಗ, computer memory ಯಲ್ಲಿ ಒಂದು ಭಾಗವನ್ನು ಮೀಸಲಿಡುತ್ತದೆ. ಅದರಲ್ಲಿ ಎಲ್ಲಾ
boxes ಒಂದರ ಪಕ್ಕದಲ್ಲೇ ಒಂದು ಇರುತ್ತವೆ, ಮತ್ತು ಪ್ರತಿ box ನ size ಒಂದೇ. ಆದ್ದರಿಂದ ಯಾವ box ಎಲ್ಲಿದೆ ಎಂದು
ಒಂದು ಸಣ್ಣ ಲೆಕ್ಕದಿಂದಲೇ computer ಕಂಡುಹಿಡಿಯುತ್ತದೆ:

```text
address of box i = address of box 0 + i * size of one box
```

Box `0` address `1000` ನಲ್ಲಿ ಶುರುವಾಗಿ, ಪ್ರತಿ box 4 bytes ತೆಗೆದುಕೊಂಡರೆ, box `3` address
`1000 + 3 * 4 = 1012` ನಲ್ಲಿದೆ. ಹುಡುಕುವುದೂ ಇಲ್ಲ, ಎಣಿಸುವುದೂ ಇಲ್ಲ: ಅದಕ್ಕೇ ಯಾವ box ಅನ್ನಾದರೂ ಓದುವುದು
ತಕ್ಷಣ ಆಗುತ್ತದೆ.

ನಾವು ನಿಗದಿತ ಸಂಖ್ಯೆಯ boxes ಇರುವ array ಕಟ್ಟುತ್ತೇವೆ, ಆ ಸಂಖ್ಯೆಯೇ ಅದರ **capacity**. ಜೊತೆಗೆ, ಎಷ್ಟು
boxes ಬಳಕೆಯಲ್ಲಿವೆ ಎಂದು ಎಣಿಸುವ **size** ಎಂಬ ಇನ್ನೊಂದು number ಇಡುತ್ತೇವೆ. Values ಯಾವಾಗಲೂ box `0`
ಯಿಂದ `size - 1` ರವರೆಗೆ ಇರುತ್ತವೆ, ಮಧ್ಯದಲ್ಲಿ ಖಾಲಿ ಜಾಗ ಇಲ್ಲದೆ.

> **ನಾವೇ ಏಕೆ ಕಟ್ಟಬೇಕು?** Python ನ `list`, C++ ನ `std::vector`, Java ದ `ArrayList` ಮತ್ತು
> JavaScript ನ array, ಇವೆಲ್ಲವೂ ಒಳಗೆ arrays ಆಗಿದ್ದು ನಿಮಗಾಗಿ ತಾವೇ ಬೆಳೆಯುತ್ತವೆ. ಒಂದು fixed array
> ಅನ್ನು ನೀವೇ ಕಟ್ಟಿದರೆ, ಅವು ತೆರೆಮರೆಯಲ್ಲಿ ಮಾಡುವ ಸರಿಸುವ ಕೆಲಸವನ್ನು ನೋಡಬಹುದು, ಮತ್ತು ಕೆಲವು operations
> ಏಕೆ ವೇಗ, ಕೆಲವು ಏಕೆ ನಿಧಾನ ಎಂದು ಅರ್ಥವಾಗುತ್ತದೆ.

## Operations

### get: ಒಂದು index ನಲ್ಲಿರುವ value ಓದುವುದು

1. Index `0` ಗಿಂತ ಕಡಿಮೆ ಇದ್ದರೆ, ಅಥವಾ `size` ಗಿಂತ ಚಿಕ್ಕದಲ್ಲದಿದ್ದರೆ, ಅಲ್ಲಿ ಯಾವ value ಕೂಡ ಇಲ್ಲ. ಆದ್ದರಿಂದ
   ನಾವು **index out of range** error ಕೊಟ್ಟು ನಿಲ್ಲಿಸುತ್ತೇವೆ.
2. ಇಲ್ಲದಿದ್ದರೆ, ಆ box ನಲ್ಲಿರುವ value ಅನ್ನು return ಮಾಡಿ. Loop ಬೇಕಾಗಿಲ್ಲ.

### insert: ಒಂದು index ನಲ್ಲಿ value ಇಡುವುದು

Values ಪಕ್ಕಪಕ್ಕದಲ್ಲೇ ಇರಬೇಕು, ಆದ್ದರಿಂದ `index` ನಲ್ಲಿ ಜಾಗ ಮಾಡಲು, `index` ನಿಂದ ಮುಂದಿನ ಪ್ರತಿ value
ಒಂದು box ಬಲಕ್ಕೆ ಸರಿಯುತ್ತದೆ.

1. `size` ಮತ್ತು `capacity` ಸಮವಾಗಿದ್ದರೆ, ಎಲ್ಲಾ boxes ತುಂಬಿವೆ, ಆದ್ದರಿಂದ ನಾವು **array is full**
   ಕೊಟ್ಟು ನಿಲ್ಲಿಸುತ್ತೇವೆ.
2. Index `0` ಯಿಂದ `size` ವರೆಗೆ ಯಾವುದಾದರೂ ಆಗಬಹುದು. `size` ನಲ್ಲಿ insert ಮಾಡುವುದು ಎಂದರೆ ಕೊನೆಗೆ
   ಸೇರಿಸುವುದು, ಆಗ ಏನನ್ನೂ ಸರಿಸಬೇಕಿಲ್ಲ.
3. **ಕೊನೆಯಿಂದ** ಶುರು ಮಾಡಿ, `index` ತಲುಪುವವರೆಗೆ ಪ್ರತಿ value ಅನ್ನು ಒಂದು box ಬಲಕ್ಕೆ ಸರಿಸಿ.
4. ಹೊಸ value ಅನ್ನು `index` ನಲ್ಲಿ ಇಡಿ, ಮತ್ತು `size` ಗೆ ಒಂದು ಸೇರಿಸಿ.

<!-- code: insert -->

ಕೊನೆಯಿಂದಲೇ ಏಕೆ ಶುರು ಮಾಡಬೇಕು? ನೀವು ಮೊದಲು `index` ನಲ್ಲಿರುವ value ಅನ್ನು ಸರಿಸಿದರೆ, ಅದರ ಪಕ್ಕದ value
ಸರಿಯುವ ಮೊದಲೇ ಅದರ ಮೇಲೆ ಬರೆದುಬಿಡುತ್ತದೆ. ಬಲದಿಂದ ಎಡಕ್ಕೆ ಹೋದರೆ, ನೀವು ಬರೆಯುವ ಪ್ರತಿ box ನ value ಈಗಾಗಲೇ
copy ಆಗಿರುತ್ತದೆ.

### remove: ಒಂದು index ನಲ್ಲಿರುವ value ತೆಗೆದುಹಾಕುವುದು

1. `get` ಮಾಡುವಂತೆಯೇ index ಪರಿಶೀಲಿಸಿ.
2. `index` ನಲ್ಲಿರುವ value ಅನ್ನು ನೆನಪಿಟ್ಟುಕೊಳ್ಳಿ.
3. ಖಾಲಿ ಜಾಗ ತುಂಬಿಸಿ: ಅದರ ನಂತರದ ಪ್ರತಿ value ಅನ್ನು ಒಂದು box ಎಡಕ್ಕೆ ಸರಿಸಿ.
4. `size` ನಿಂದ ಒಂದು ಕಳೆಯಿರಿ, ಮತ್ತು ನೆನಪಿಟ್ಟ value ಅನ್ನು return ಮಾಡಿ.

<!-- code: remove -->

ಕೊನೆಯ box ನಲ್ಲಿ ಇನ್ನೂ ಒಂದು value ನ ಹಳೆಯ copy ಇರುತ್ತದೆ, ಆದರೆ ಅದು ಈಗ `size` ನ ಹೊರಗಿದೆ, ಆದ್ದರಿಂದ
array ನ ಭಾಗವಲ್ಲ. ಮೇಲಿನ playground ನಲ್ಲಿ ಈ ಹಳೆಯ copies ಮಸುಕಾಗಿ ಕಾಣುತ್ತವೆ.

### search: ಒಂದು value ಎಲ್ಲಿದೆ ಎಂದು ಹುಡುಕುವುದು

ಪ್ರತಿ box ನಲ್ಲಿ ಏನಿದೆ ಎಂದು array ಗೆ ಗೊತ್ತು, ಆದರೆ ಒಂದು ನಿರ್ದಿಷ್ಟ value ಎಲ್ಲಿದೆ ಎಂದು ಗೊತ್ತಿಲ್ಲ.
ಆದ್ದರಿಂದ `search` index `0` ಯಿಂದ ಶುರು ಮಾಡಿ boxes ಅನ್ನು ಒಂದೊಂದಾಗಿ ನೋಡುತ್ತದೆ, ಮತ್ತು ಮೊದಲು ಹೊಂದುವ
index ಅನ್ನು return ಮಾಡುತ್ತದೆ; value ಇಲ್ಲದಿದ್ದರೆ `-1`. ಇದನ್ನು **linear search** ಎನ್ನುತ್ತಾರೆ.

## ಇದು ಎಷ್ಟು ವೇಗವಾಗಿದೆ?

| Operation | ಇದು ಏನು ಮಾಡುತ್ತದೆ | Time |
|---|---|---|
| `get` | ಒಂದು index ನ box ಓದುವುದು | `O(1)` |
| ಕೊನೆಗೆ `insert` | box `size` ನಲ್ಲಿ ಬರೆಯುವುದು, ಏನೂ ಸರಿಯುವುದಿಲ್ಲ | `O(1)` |
| ಒಂದು index ನಲ್ಲಿ `insert` | ಹೆಚ್ಚೆಂದರೆ `size` values ಅನ್ನು ಬಲಕ್ಕೆ ಸರಿಸುವುದು | `O(n)` |
| ಕೊನೆಯಿಂದ `remove` | ಏನೂ ಸರಿಯುವುದಿಲ್ಲ | `O(1)` |
| ಒಂದು index ನಿಂದ `remove` | ಹೆಚ್ಚೆಂದರೆ `size` values ಅನ್ನು ಎಡಕ್ಕೆ ಸರಿಸುವುದು | `O(n)` |
| `search` | boxes ಅನ್ನು ಒಂದೊಂದಾಗಿ ನೋಡುವುದು | `O(n)` |

ಇಲ್ಲಿ `n` ಎಂದರೆ values ನ ಸಂಖ್ಯೆ. Index `0` ನಲ್ಲಿ insert ಮಾಡುವುದು ಅತ್ಯಂತ ನಿಧಾನ, ಏಕೆಂದರೆ ಪ್ರತಿಯೊಂದು
value ಕೂಡ ಸರಿಯಬೇಕು. `n` values ಗೆ ಜಾಗ ಇರುವ array ಗೆ `O(n)` memory ಬೇಕು, ಅದರ ಹೆಚ್ಚಿನ boxes ಖಾಲಿ
ಇದ್ದರೂ ಸಹ.

## ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು

- **1 ರಿಂದ ಎಣಿಸುವುದು.** ಮೊದಲ box index `0`, ಕೊನೆಯದು `size - 1`. Index `size` ಒಂದು ಹೆಜ್ಜೆ ಮುಂದೆ
  ಹೋಗುತ್ತದೆ.
- **Size ಮತ್ತು capacity ನಡುವೆ ಗೊಂದಲ.** `capacity` ಎಂದರೆ ಎಷ್ಟು boxes ಇವೆ; `size` ಎಂದರೆ ಅವುಗಳಲ್ಲಿ
  ಎಷ್ಟರಲ್ಲಿ ನಿಜವಾದ values ಇವೆ.
- **ತಪ್ಪು ದಿಕ್ಕಿನಲ್ಲಿ ಸರಿಸುವುದು.** `insert` ಗೆ ಕೊನೆಯಿಂದ index ಕಡೆಗೆ copy ಮಾಡಿ. `remove` ಗೆ index
  ನಿಂದ ಕೊನೆಯ ಕಡೆಗೆ. ಉಲ್ಟಾ ಮಾಡಿದರೆ values ಸರಿಯುವ ಮೊದಲೇ ಅಳಿಸಿಹೋಗುತ್ತವೆ.
- **Size ಬದಲಿಸಲು ಮರೆಯುವುದು.** ಪ್ರತಿ insert ಒಂದು ಸೇರಿಸುತ್ತದೆ, ಪ್ರತಿ remove ಒಂದು ಕಳೆಯುತ್ತದೆ.
- **ಮತ್ತೆ ಮತ್ತೆ ಮುಂಭಾಗದಲ್ಲಿ insert ಮಾಡುವುದು.** ಪ್ರತಿ insert ಎಲ್ಲವನ್ನೂ ಸರಿಸುತ್ತದೆ, ಆದ್ದರಿಂದ ಹೀಗೆ
  `n` values ಸೇರಿಸಲು `O(n²)` time ಬೇಕು. ಸಾಧ್ಯವಾದಾಗಲೆಲ್ಲ ಕೊನೆಗೆ ಸೇರಿಸಿ.

## ಇದು ಎಲ್ಲಿ ಬಳಕೆಯಾಗುತ್ತದೆ?

- **ಬಹುತೇಕ ಎಲ್ಲೆಡೆ.** Lists, vectors, ArrayLists ಮತ್ತು JavaScript arrays, ಎಲ್ಲವೂ arrays ಮೇಲೆಯೇ
  ಕಟ್ಟಲ್ಪಟ್ಟಿವೆ.
- **Images.** ಒಂದು photo ಎಂದರೆ pixel colours ನ ಒಂದು ದೊಡ್ಡ array.
- **Class register ನ marks.** ಪ್ರತಿ roll number ಗೆ ಒಂದು mark: roll number ಅನ್ನೇ index ಆಗಿ
  ಬಳಸುತ್ತೇವೆ.
- **Lookup tables**, ಉದಾಹರಣೆಗೆ ಪ್ರತಿ ತಿಂಗಳಿನ ದಿನಗಳ ಸಂಖ್ಯೆ; ಇಲ್ಲಿ index ತಕ್ಷಣ ಉತ್ತರ ಕೊಡುತ್ತದೆ.
- **ಇತರ structures.** ಈ course ನ stack ಮತ್ತು queue ಕೂಡ arrays ಮೇಲೆ ಕಟ್ಟಲ್ಪಟ್ಟಿವೆ.

## ಇವುಗಳನ್ನು ಮಾಡಿ ನೋಡಿ

1. `[3, 9, 4]` ನಲ್ಲಿ index `1` ನಲ್ಲಿ `7` insert ಮಾಡಿ. ಯಾವ values ಸರಿಯುತ್ತವೆ, ಯಾವ ಕ್ರಮದಲ್ಲಿ? ನಿಮ್ಮ
   ಉತ್ತರವನ್ನು playground ನಲ್ಲಿ ಪರಿಶೀಲಿಸಿ.
2. Array ನ ಅತಿ ದೊಡ್ಡ value ಅನ್ನು return ಮಾಡುವ ಒಂದು function ಬರೆಯಿರಿ. ಅದು ಎಷ್ಟು boxes ನೋಡಬೇಕು?
3. Array ಅನ್ನು ಅದೇ ಜಾಗದಲ್ಲಿ ತಿರುಗಿಸುವ ಒಂದು function ಬರೆಯಿರಿ: ಮೊದಲ ಮತ್ತು ಕೊನೆಯ values ಅದಲುಬದಲು
   ಮಾಡಿ, ನಂತರ ಎರಡನೆಯದು ಮತ್ತು ಕೊನೆಯಿಂದ ಎರಡನೆಯದು, ಹೀಗೆಯೇ ಮುಂದುವರಿಸಿ.
4. ತುಂಬಿದ array ತನ್ನ capacity ಯನ್ನು ಎರಡರಷ್ಟು ಮಾಡಿಕೊಳ್ಳುವಂತೆ `insert` ಬದಲಿಸಿ: ಎರಡರಷ್ಟು ದೊಡ್ಡ ಹೊಸ
   array ರಚಿಸಿ, ಪ್ರತಿ value ಅನ್ನು ಅದಕ್ಕೆ copy ಮಾಡಿ, ನಂತರ insert ಮಾಡಿ. Python lists ಮತ್ತು C++
   vectors ಹೀಗೆಯೇ ಬೆಳೆಯುತ್ತವೆ.
