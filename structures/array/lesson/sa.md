**Array** इति memory इत्यस्मिन् परस्परं संलग्नानां boxes इत्येतेषाम् एका पङ्क्तिः। प्रत्येकं box एकं
number धारयति, यत् तस्य **index** इति कथ्यते, गणना च `0` तः आरभते। यदि यूयम् index जानीथ, तर्हि
यूयं साक्षात् किमपि box प्राप्नुथ। अतः values इत्येतासां list रक्षितुं सर्वाधिकं सरलः शीघ्रतमः च
उपायः array एव।

## वास्तविकजीवने

Cinema hall इत्यस्य एकस्यां पङ्क्तौ स्थितानि seats चिन्तयत। Seats भूमौ दृढं स्थापितानि सन्ति, एकम्
अपरस्य पश्चात्, प्रत्येकं च एकं number धारयति। यदि युष्माकं ticket इत्यस्मिन् seat 7 इति लिखितम्,
तर्हि यूयं प्रथमं seat 1 तः 6 पर्यन्तं न पश्यथ। यूयं साक्षात् seat 7 इत्यत्र गच्छथ।

Train इत्यस्य sleeper coach अपि एवमेव कार्यं करोति। युष्माकं berth number युष्मान् यथावत् कथयति
कुत्र गन्तव्यम् इति, coach इत्यस्मिन् च berths इत्येतेषां संख्या निश्चिता भवति: coach रचिते सति
कोऽपि तस्मिन् अधिकम् एकं berth योजयितुं न शक्नोति।

एतयोः उदाहरणयोः द्वे विचारे arrays कृते महत्त्वपूर्णे स्तः:

- **Number युक्तानि स्थानानि।** प्रत्येकस्याः value इत्यस्याः एकं स्थानम् अस्ति, यत्र यूयं साक्षात्
  गन्तुं शक्नुथ।
- **निश्चिता दीर्घता।** पङ्क्तौ स्थानानां संख्या निश्चिता भवति। अधिकं स्थानम् अपेक्षितं चेत् नवीना
  बृहत्तरा च पङ्क्तिः आवश्यकी।

एकः भेदः: cinema इत्यस्य seats प्रायः 1 तः आरभन्ते, किन्तु code इत्यस्मिन् प्रथमं box index `0`
भवति।

## एतत् कथं कार्यं करोति

यदा किमपि program array रचयति, तदा computer memory इत्यस्य एकं खण्डम् आरक्षयति, यस्मिन् सर्वे boxes
परस्परं समीपे एव भवन्ति, प्रत्येकं box च समानं size धारयति। अतः सः एकेन लघुना गणनेन जानाति किमपि box
कुत्र अस्ति इति:

```text
address of box i = address of box 0 + i * size of one box
```

यदि box `0` address `1000` इत्यस्मात् आरभते, प्रत्येकं box च 4 bytes गृह्णाति, तर्हि box `3` address
`1000 + 3 * 4 = 1012` इत्यत्र अस्ति। न अन्वेषणं, न गणना: अतः एव कस्यापि box इत्यस्य पठनं तत्क्षणमेव
भवति।

वयम् एकम् array रचयिष्यामः यस्मिन् boxes इत्येतेषां संख्या निश्चिता, अर्थात् तस्य **capacity**, तथा
द्वितीयम् एकं number रक्षिष्यामः, **size**, यत् गणयति कति boxes प्रयोगे सन्ति इति। Values सदा box `0`
तः `size - 1` पर्यन्तं तिष्ठन्ति, मध्ये किमपि रिक्तं स्थानं नास्ति।

> **एतत् स्वयं किमर्थं रचयामः?** Python इत्यस्य `list`, C++ इत्यस्य `std::vector`, Java इत्यस्य
> `ArrayList`, JavaScript इत्यस्य array च, एते सर्वे अन्तः arrays एव, ये युष्मदर्थं स्वयमेव वर्धन्ते।
> (PHP इत्यस्य array वस्तुतः एकः ordered map अस्ति; PHP इत्यस्मिन् boxes इत्येतेषां निश्चितायाः पङ्क्तेः
> निकटतमं `SplFixedArray` अस्ति।) एकं fixed array स्वयं रचयित्वा यूयं तत् स्थानान्तरणं पश्यथ यत् एते
> पृष्ठतः कुर्वन्ति, तथा च जानीथ केचन operations शीघ्राः किमर्थं, केचन च मन्दाः किमर्थम् इति।

## Operations

### get: कस्यचित् index इत्यस्य value पठनम्

1. यदि index `0` तः न्यूनः, अथवा `size` तः लघुतरः नास्ति, तर्हि तत्र काऽपि value नास्ति, अतः वयम्
   **index out of range** इति error दत्त्वा विरमामः।
2. अन्यथा, तस्य box इत्यस्य value प्रत्यर्पयत। कोऽपि loop न अपेक्षितः।

### insert: कस्मिंश्चित् index इत्यस्मिन् value स्थापनम्

Values परस्परं संलग्नाः एव स्थातव्याः, अतः `index` इत्यस्मिन् स्थानं कर्तुं `index` तः आरभ्य अग्रे
स्थिता प्रत्येका value एकं box दक्षिणतः सरति।

1. यदि `size` तथा `capacity` समाने, तर्हि प्रत्येकं box पूर्णम्, अतः वयम् **array is full** इति
   दत्त्वा विरमामः।
2. Index `0` तः `size` पर्यन्तं किमपि भवितुम् अर्हति। `size` इत्यस्मिन् insert इत्यस्य अर्थः अन्ते
   योजनम्, तदा च किमपि स्थानान्तरणं न आवश्यकम्।
3. **अन्तात्** आरभ्य, प्रत्येकां value एकं box दक्षिणतः सारयत, यावत् `index` न प्राप्यते।
4. नवीनां value `index` इत्यस्मिन् स्थापयत, `size` इत्यस्मिन् च एकं योजयत।

<!-- code: insert -->

अन्तात् एव किमर्थम् आरभ्यते? यदि यूयं प्रथमं `index` इत्यस्मिन् स्थितां value सारयथ, तर्हि सा स्वस्य
समीपस्थायाः value इत्यस्याः सरणात् पूर्वमेव तस्याः उपरि लिखति। दक्षिणतः वामं गच्छन्तः यूयं यस्मिन्
box इत्यस्मिन् लिखथ, तस्य value पूर्वमेव copy कृता अस्ति।

### remove: कस्यचित् index इत्यस्य value अपनयनम्

1. Index परीक्षध्वम्, यथा `get` करोति तथैव।
2. `index` इत्यस्मिन् स्थितां value स्मरत।
3. रिक्तं स्थानं पूरयत: तस्याः पश्चात् स्थितां प्रत्येकां value एकं box वामतः सारयत।
4. `size` इत्यस्मात् एकं न्यूनीकुरुत, स्मृतां च value प्रत्यर्पयत।

<!-- code: remove -->

अन्तिमं box अद्यापि कस्याश्चित् value इत्यस्याः पुरातनां copy धारयति, किन्तु तत् इदानीं `size` इत्यस्मात्
बहिः अस्ति, अतः array इत्यस्य भागः नास्ति। उपरि playground इत्यस्मिन् एताः पुरातनाः copies मन्दवर्णेन
दृश्यन्ते।

### search: काचित् value कुत्र अस्ति इति अन्वेषणम्

Array जानाति प्रत्येकस्मिन् box इत्यस्मिन् किम् अस्ति इति, किन्तु काचित् विशिष्टा value कुत्र अस्ति
इति न जानाति। अतः `search` index `0` तः आरभ्य boxes एकैकशः पश्यति, तथा यस्मिन् सा value अस्ति तत्
प्रथमम् index प्रत्यर्पयति, value न लभ्यते चेत् `-1`। एतत् **linear search** इति कथ्यते।

## एतत् कियत् शीघ्रम्?

| Operation | एतत् किं करोति | Time |
|---|---|---|
| `get` | कस्यचित् index इत्यस्य box पठनम् | `O(1)` |
| अन्ते `insert` | box `size` इत्यस्मिन् लेखनम्, किमपि न सरति | `O(1)` |
| कस्मिंश्चित् index इत्यस्मिन् `insert` | अधिकतमं `size` values दक्षिणतः स्थानान्तरणम् | `O(n)` |
| अन्तात् `remove` | किमपि न सरति | `O(1)` |
| कस्माच्चित् index इत्यस्मात् `remove` | अधिकतमं `size` values वामतः स्थानान्तरणम् | `O(n)` |
| `search` | boxes एकैकशः परीक्षणम् | `O(n)` |

अत्र `n` values इत्येतासां संख्या। Index `0` इत्यस्मिन् insert सर्वाधिकं मन्दम्, यतः प्रत्येका value
सारणीया भवति। `n` values कृते स्थानयुक्तम् array `O(n)` memory अपेक्षते, यद्यपि तस्य अधिकांशाः boxes
रिक्ताः स्युः।

## सामान्याः त्रुटयः

- **1 तः गणना।** प्रथमं box index `0`, अन्तिमं च `size - 1`। Index `size` एकं पदम् अग्रे अस्ति।
- **Size तथा capacity इत्यनयोः सम्मिश्रणम्।** `capacity` कथयति कति boxes सन्ति इति; `size` कथयति
  तेषु कति वास्तविकाः values धारयन्ति इति।
- **विपरीतदिशि स्थानान्तरणम्।** `insert` इत्यस्मिन् अन्तात् index इत्यस्य दिशि copy कुरुत। `remove`
  इत्यस्मिन् index इत्यस्मात् अन्तस्य दिशि। विपरीतं कृते values सरणात् पूर्वमेव नश्यन्ति।
- **Size परिवर्तनस्य विस्मरणम्।** प्रत्येकं insert एकं योजयति, प्रत्येकं च remove एकं न्यूनीकरोति।
- **पुनः पुनः अग्रे insert।** प्रत्येकं insert सर्वं सारयति, अतः एवं `n` values योजनाय `O(n²)` time
  अपेक्ष्यते। यदा शक्यं, तदा अन्ते योजयत।

## एतत् कुत्र प्रयुज्यते?

- **प्रायः सर्वत्र।** Lists, vectors, ArrayLists, JavaScript arrays च सर्वे arrays इत्येतेषाम् उपरि
  एव रचिताः।
- **Images।** एकं photo pixel colours इत्येतेषां बृहत् array अस्ति।
- **Class register इत्यस्य marks।** प्रत्येकस्य roll number कृते एकं mark: roll number एव index।
- **Lookup tables**, यथा प्रत्येकस्य मासस्य दिनानां संख्या, यत्र index तत्क्षणम् उत्तरं ददाति।
- **अन्ये structures।** अस्य course इत्यस्य stack तथा queue अपि arrays इत्येतेषाम् उपरि रचितौ।

## एतानि कृत्वा पश्यत

1. `[3, 9, 4]` इत्यस्मिन् index `1` इत्यत्र `7` insert कुरुत। काः values सरन्ति, कस्मिन् च क्रमे?
   स्वम् उत्तरं playground इत्यस्मिन् परीक्षध्वम्।
2. एकं function लिखत यत् array इत्यस्य महत्तमां value प्रत्यर्पयति। तत् कति boxes द्रष्टव्यानि?
3. एकं function लिखत यत् array तस्मिन्नेव स्थाने विपरीतं करोति: प्रथमां अन्तिमां च value परस्परं
   परिवर्तयत, ततः द्वितीयां तथा अन्तात् द्वितीयां, एवम् अग्रे।
4. `insert` एवं परिवर्तयत यथा पूर्णम् array स्वस्य capacity द्विगुणं करोति: द्विगुणं बृहत् नवीनम्
   array रचयत, प्रत्येकां value तस्मिन् copy कुरुत, ततः insert कुरुत। Python lists तथा C++ vectors
   एवमेव वर्धन्ते।
