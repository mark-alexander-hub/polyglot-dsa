**Linked list** इति लघूनां boxes इत्येतेषाम् एका शृङ्खला, ये **nodes** इति कथ्यन्ते। प्रत्येकः node
एकां value तथा अग्रिमस्य node इत्यस्य address धारयति। List इत्यस्यां गन्तुं यूयं प्रथमात् node
इत्यस्मात् आरभध्वे, यः **head** इति कथ्यते, ततः links एकैकशः अनुसरथ, यावत् कोऽपि अग्रिमः node न
अवशिष्यते।

## वास्तविकजीवने

एकं train चिन्तयत। प्रत्येकः coach स्वस्य पश्चात् स्थितेन coach इत्यनेन सह संयुक्तः अस्ति। यूयम् अग्रे
एकं coach योजयितुं शक्नुथ, अन्ते एकं योजयितुं शक्नुथ, अथवा मध्यात् एकं वियोज्य तस्य उभयतः स्थितौ
coaches परस्परं संयोजयितुं शक्नुथ। अन्ये coaches स्वस्थानात् किञ्चिदपि न चलन्ति।

Treasure hunt अपि एवमेव चलति। प्रथमः clue कथयति द्वितीयः clue कुत्र गुप्तः इति, द्वितीयः कथयति
तृतीयः कुत्र इति, एवम् अग्रे। यूयं साक्षात् clue संख्या 5 इत्यत्र गन्तुं न शक्नुथ: युष्माभिः आरम्भात्
शृङ्खला अनुसर्तव्या।

## एतत् कथं कार्यं करोति

Array इत्यस्मिन् values memory इत्यस्य एकस्मिन् खण्डे परस्परं समीपे तिष्ठन्ति। Linked list भिन्ना:
प्रत्येकः node memory इत्यस्मिन् कुत्रापि भवितुम् अर्हति। Nodes परस्परं यत् संयोजयति, तत् प्रत्येकस्य
node इत्यस्य अन्तः स्थितः `next` link।

- `head` प्रथमं node निर्दिशति। यदि list रिक्ता, तर्हि `head` `null` भवति।
- अन्तिमस्य node इत्यस्य `next` `null` भवति, यस्य अर्थः "शृङ्खला अत्रैव समाप्यते"।

(`null` Python इत्यस्मिन् `None` इति, C++ इत्यस्मिन् च `nullptr` इति कथ्यते।)

स्वं size कथयितुं शक्नोति।

| Extra memory | किमपि न | प्रत्येकस्मिन् node इत्यस्मिन् एकः link |

## Operations

### add-first: अग्रे नवीनस्य node इत्यस्य स्थापनम्

1. Value कृते एकं नवीनं node रचयत।
2. नवीनस्य node इत्यस्य `next` इत्यनेन वर्तमानं head निर्दिशत।
3. `head` नवीनं node नयत।

क्रमः महत्त्वपूर्णः। यदि यूयं प्रथमं `head` चालयथ, तर्हि पुरातनस्य प्रथमस्य node इत्यस्य address
नश्यति, तेन सह च शेषा सम्पूर्णा list अपि।

<!-- code: add-first -->

### add-last: अन्ते नवीनस्य node इत्यस्य स्थापनम्

1. Value कृते एकं नवीनं node रचयत।
2. यदि list रिक्ता, तर्हि नवीनः node एव head भवति, कार्यं च समाप्तम्।
3. अन्यथा, head इत्यस्मात् आरभध्वम्, `next` अनुसरत यावत् सः node न लभ्यते यस्य `next` `null` अस्ति।
   सः एव अन्तिमः node।
4. अन्तिमस्य node इत्यस्य `next` इत्यनेन नवीनं node निर्दिशत।

<!-- code: add-last -->

### find: किम् एषा value list इत्यस्याम् अस्ति?

Head इत्यस्मात् आरभध्वम्, प्रत्येकं node क्रमेण परीक्षध्वम्। यदि कस्मिंश्चित् node इत्यस्मिन् सा value
अस्ति, तर्हि उत्तरम् "आम्"। यदि यूयम् अन्तिमं node अतिक्रम्य `null` प्राप्नुथ, तर्हि उत्तरम् "न"।

<!-- code: find -->

### remove: कांचित् value धारयतः प्रथमस्य node इत्यस्य अपनयनम्

1. यदि list रिक्ता, तर्हि अपनेतुं किमपि नास्ति, अतः error दत्त्वा विरमत।
2. यदि head एव तां value धारयति, तर्हि `head` द्वितीयं node नयत। पुरातनः प्रथमः node इदानीं
   शृङ्खलायाः भागः नास्ति।
3. अन्यथा, `previous` इति नाम्ना pointer इत्यनेन सह तावत् गच्छत यावत् `previous.next` तां value न
   धारयति। यदि ततः पूर्वमेव यूयम् अन्तं प्राप्नुथ, तर्हि सा value list इत्यस्यां नास्ति: error दत्त्वा
   विरमत।
4. `previous.next` इत्यनेन तं node अतिक्रम्य तस्य पश्चात् स्थितं node निर्दिशत। इदानीं शृङ्खला तं
   node त्यक्त्वा अग्रे गच्छति।

<!-- code: remove -->

चतुर्थे step इत्यस्मिन् relinking एका एव line, `O(1)` च अपेक्षते। समयः तु तं node अन्वेष्टुं गमने एव
व्ययः भवति।

## एतत् कियत् शीघ्रम्?

| Operation | एतत् किं करोति | Time |
|---|---|---|
| `add-first` | अग्रे नवीनः node | `O(1)` |
| `add-last` | अन्तं यावत् गमनम्, ततः योजनम् | `O(n)` |
| `find` | nodes एकैकशः परीक्षणम् | `O(n)` |
| `remove` | node यावत् गमनम्, ततः relink | `O(n)` |
| `size` | counter इत्यस्य पठनम् | `O(1)` |

> **Tail pointer इत्यनेन शीघ्रतरम् add-last।** यदि list स्वम् अन्तिमं node अपि `tail` इति नाम्नि field
> इत्यस्मिन् स्मरति, तर्हि `add-last` कृते गमनं न आवश्यकम्: नवीनं node `tail` इत्यस्य पश्चात् योजयत,
> ततः `tail` तं नयत। तेन `add-last` `O(1)` भवति, यत् queue रचनायां बहु उपयोगि।

`n` nodes युक्ता list `O(n)` memory अपेक्षते, प्रत्येकः node च एकम् अतिरिक्तं link वहति।

## सामान्याः त्रुटयः

- **Links इत्येतेषां विपरीतक्रमेण परिवर्तनम्।** `add-first` इत्यस्मिन् यदि यूयं `node.next = head`
  इत्यस्मात् पूर्वं `head = node` लिखथ, तर्हि नवीनः node स्वयमेव स्वं निर्दिशति, शेषा list च नश्यति।
  सदा प्रथमं नवीनं node संयोजयत, ततः पुरातनं pointer चालयत।
- **Head इत्यस्य case इत्यस्य विस्मरणम्।** प्रथमस्य node इत्यस्य अपनयनं विशेषम्: तस्मात् पूर्वं कोऽपि
  `previous` node नास्ति, अतः युष्माभिः `head` एव चालनीयः। बहवः bugs अत्रैव गुप्ताः भवन्ति।
- **अन्तम् अतिक्रम्य गमनम्।** कस्यचित् node इत्यस्य `value` अथवा `next` पठनात् पूर्वं परीक्षध्वं सः
  node `null` नास्ति इति।
- **गणनायाः नाशः।** यत् किमपि method node योजयति अपनयति वा, तस्मिन् प्रत्येकस्मिन् counter परिवर्तयत।
- **C++ इत्यस्मिन् memory leaks।** `new` इत्यनेन रचितः प्रत्येकः node `delete` इत्यनेन मोचनीयः,
  `remove` इत्यस्मिन् अपि destructor इत्यस्मिन् अपि। Python, Java, JavaScript, PHP च अप्रयुक्तान् nodes
  युष्मदर्थं स्वयं शोधयन्ति।

## एतत् कुत्र प्रयुज्यते?

- "Next" तथा "previous" buttons युक्ताः **music playlists तथा photo galleries**। एताः *doubly*
  linked list प्रयुञ्जते, यस्यां प्रत्येकः node स्वस्मात् पूर्वं स्थितं node अपि निर्दिशति।
- **Hash tables** एकस्मिन्नेव slot इत्यस्मिन् आगतानां values कृते लघ्वीः linked lists रक्षन्ति।
- **Stacks तथा queues** linked list इत्यस्याः उपरि रचयितुं शक्यन्ते, येन ते कदापि पूर्णाः न भवन्ति।
- **Operating systems** चलतः programs तथा memory इत्यस्य रिक्तान् खण्डान् linked lists इत्येतासु
  रक्षन्ति।
