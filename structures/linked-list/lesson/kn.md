**Linked list** ಎಂದರೆ **nodes** ಎಂಬ ಸಣ್ಣ boxes ಗಳ ಒಂದು chain. ಪ್ರತಿ node ನಲ್ಲಿ ಒಂದು value ಮತ್ತು
ಮುಂದಿನ node ನ address ಇರುತ್ತದೆ. List ನಲ್ಲಿ ಮುಂದೆ ಹೋಗಲು ನೀವು ಮೊದಲ node ನಿಂದ ಶುರು ಮಾಡುತ್ತೀರಿ, ಅದನ್ನು
**head** ಎನ್ನುತ್ತಾರೆ. ನಂತರ ಮುಂದಿನ node ಇಲ್ಲದಾಗುವವರೆಗೂ links ಅನ್ನು ಒಂದೊಂದಾಗಿ ಹಿಂಬಾಲಿಸುತ್ತೀರಿ.

## ನಿಜ ಜೀವನದಲ್ಲಿ

ಒಂದು train ಬಗ್ಗೆ ಯೋಚಿಸಿ. ಪ್ರತಿ coach ತನ್ನ ಹಿಂದಿನ coach ಗೆ ಜೋಡಿಸಲ್ಪಟ್ಟಿರುತ್ತದೆ. ನೀವು ಮುಂದೆ ಒಂದು coach
ಸೇರಿಸಬಹುದು, ಕೊನೆಯಲ್ಲಿ ಒಂದು ಸೇರಿಸಬಹುದು, ಅಥವಾ ಮಧ್ಯದಿಂದ ಒಂದು coach ಬೇರ್ಪಡಿಸಿ ಅದರ ಮುಂದಿನ ಮತ್ತು ಹಿಂದಿನ
coaches ಅನ್ನು ಒಟ್ಟಿಗೆ ಜೋಡಿಸಬಹುದು. ಉಳಿದ coaches ತಮ್ಮ ಜಾಗದಿಂದ ಅಲುಗಾಡುವ ಅಗತ್ಯವೇ ಇಲ್ಲ.

Treasure hunt ಕೂಡ ಹೀಗೆಯೇ ನಡೆಯುತ್ತದೆ. ಮೊದಲ clue ಎರಡನೇ clue ಎಲ್ಲಿ ಅಡಗಿದೆ ಎಂದು ಹೇಳುತ್ತದೆ, ಎರಡನೆಯದು
ಮೂರನೆಯದು ಎಲ್ಲಿದೆ ಎಂದು ಹೇಳುತ್ತದೆ, ಹೀಗೆ ಮುಂದುವರಿಯುತ್ತದೆ. ನೀವು ನೇರವಾಗಿ clue ಸಂಖ್ಯೆ 5 ಕ್ಕೆ ಹೋಗಲು
ಸಾಧ್ಯವಿಲ್ಲ: ಶುರುವಿನಿಂದಲೇ chain ಅನ್ನು ಹಿಂಬಾಲಿಸಬೇಕು.

## ಇದು ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ

Array ನಲ್ಲಿ values memory ಯ ಒಂದೇ ಭಾಗದಲ್ಲಿ ಪಕ್ಕಪಕ್ಕದಲ್ಲಿ ಇರುತ್ತವೆ. Linked list ಬೇರೆ: ಪ್ರತಿ node
memory ಯಲ್ಲಿ ಎಲ್ಲಿ ಬೇಕಾದರೂ ಇರಬಹುದು. Nodes ಅನ್ನು ಜೋಡಿಸುವುದು ಪ್ರತಿ node ಒಳಗಿನ `next` link.

- `head` ಮೊದಲ node ಕಡೆ point ಮಾಡುತ್ತದೆ. List ಖಾಲಿ ಇದ್ದರೆ `head` ನ value `null`.
- ಕೊನೆಯ node ನ `next` `null` ಆಗಿರುತ್ತದೆ, ಅಂದರೆ "chain ಇಲ್ಲಿಗೆ ಮುಗಿಯುತ್ತದೆ".

(`null` ಅನ್ನು Python ನಲ್ಲಿ `None` ಮತ್ತು C++ ನಲ್ಲಿ `nullptr` ಎನ್ನುತ್ತಾರೆ.)

ತನ್ನ size ಹೇಳಬಹುದು.

Linked list ಮತ್ತು array ಹೋಲಿಕೆ ಹೀಗಿದೆ:

| | Array | Linked list |
|---|---|---|
| Values ಎಲ್ಲಿರುತ್ತವೆ | memory ಯಲ್ಲಿ ಪಕ್ಕಪಕ್ಕದಲ್ಲಿ | ಎಲ್ಲಿ ಬೇಕಾದರೂ, links ಮೂಲಕ ಜೋಡಣೆ |
| Index 5 ರ value ಪಡೆಯುವುದು | ನೇರವಾಗಿ ಅಲ್ಲಿಗೆ ಹೋಗುವುದು, `O(1)` | head ನಿಂದ ನಡೆದು ಹೋಗುವುದು, `O(n)` |
| ಮುಂದೆ ಒಂದು value ಸೇರಿಸುವುದು | ಪ್ರತಿ value ಅನ್ನು ಬಲಕ್ಕೆ ಸರಿಸುವುದು, `O(n)` | ಎರಡು links ಬದಲಿಸುವುದು, `O(1)` |
| Extra memory | ಏನೂ ಇಲ್ಲ | ಪ್ರತಿ node ನಲ್ಲಿ ಒಂದು link |

## Operations

### add-first: ಮುಂದೆ ಒಂದು ಹೊಸ node ಇಡುವುದು

1. Value ಗಾಗಿ ಒಂದು ಹೊಸ node ಮಾಡಿ.
2. ಹೊಸ node ನ `next` ಅನ್ನು ಈಗಿನ head ಕಡೆ point ಮಾಡಿ.
3. `head` ಅನ್ನು ಹೊಸ node ಗೆ ಸರಿಸಿ.

ಕ್ರಮ ಮುಖ್ಯ. ನೀವು ಮೊದಲು `head` ಅನ್ನು ಸರಿಸಿದರೆ, ಹಳೆಯ ಮೊದಲ node ನ address ಕಳೆದುಹೋಗುತ್ತದೆ, ಅದರ ಜೊತೆ
ಉಳಿದ ಇಡೀ list ಕೂಡ.

<!-- code: add-first -->

### add-last: ಕೊನೆಯಲ್ಲಿ ಒಂದು ಹೊಸ node ಇಡುವುದು

1. Value ಗಾಗಿ ಒಂದು ಹೊಸ node ಮಾಡಿ.
2. List ಖಾಲಿ ಇದ್ದರೆ, ಹೊಸ node ತಾನೇ head ಆಗುತ್ತದೆ, ಕೆಲಸ ಮುಗಿಯಿತು.
3. ಇಲ್ಲದಿದ್ದರೆ, head ನಿಂದ ಶುರು ಮಾಡಿ, `next` `null` ಆಗಿರುವ node ಸಿಗುವವರೆಗೂ `next` ಅನ್ನು
   ಹಿಂಬಾಲಿಸಿ. ಅದೇ ಕೊನೆಯ node.
4. ಕೊನೆಯ node ನ `next` ಅನ್ನು ಹೊಸ node ಕಡೆ point ಮಾಡಿ.

<!-- code: add-last -->

### find: ಈ value list ನಲ್ಲಿ ಇದೆಯೇ?

Head ನಿಂದ ಶುರು ಮಾಡಿ, ಪ್ರತಿ node ಅನ್ನು ಒಂದರ ನಂತರ ಒಂದರಂತೆ ಪರಿಶೀಲಿಸಿ. ಯಾವುದಾದರೂ node ನಲ್ಲಿ ಆ value
ಇದ್ದರೆ ಉತ್ತರ ಹೌದು. ಕೊನೆಯ node ದಾಟಿ `null` ತಲುಪಿದರೆ ಉತ್ತರ ಇಲ್ಲ.

<!-- code: find -->

### remove: ಒಂದು value ಇರುವ ಮೊದಲ node ತೆಗೆದುಹಾಕುವುದು

1. List ಖಾಲಿ ಇದ್ದರೆ ತೆಗೆಯಲು ಏನೂ ಇಲ್ಲ, ಆದ್ದರಿಂದ error ಕೊಟ್ಟು ನಿಲ್ಲಿಸಿ.
2. Head ನಲ್ಲೇ ಆ value ಇದ್ದರೆ, `head` ಅನ್ನು ಎರಡನೇ node ಗೆ ಸರಿಸಿ. ಹಳೆಯ ಮೊದಲ node ಈಗ chain ನ ಭಾಗವಲ್ಲ.
3. ಇಲ್ಲದಿದ್ದರೆ, `previous.next` ನಲ್ಲಿ ಆ value ಸಿಗುವವರೆಗೂ `previous` ಎಂಬ pointer ಜೊತೆ ನಡೆಯಿರಿ.
   ಅದಕ್ಕೂ ಮೊದಲೇ ಕೊನೆ ತಲುಪಿದರೆ, value list ನಲ್ಲಿ ಇಲ್ಲ: error ಕೊಟ್ಟು ನಿಲ್ಲಿಸಿ.
4. `previous.next` ಅನ್ನು ಆ node ದಾಟಿ, ಅದರ ನಂತರದ node ಕಡೆ point ಮಾಡಿ. ಈಗ chain ಆ node ಅನ್ನು
   ಬಿಟ್ಟು ಮುಂದೆ ಹೋಗುತ್ತದೆ.

<!-- code: remove -->

Step 4 ರ relinking ಕೇವಲ ಒಂದು line, ಅದು `O(1)` ತೆಗೆದುಕೊಳ್ಳುತ್ತದೆ. ಸಮಯ ಹಿಡಿಯುವುದು ಆ node ಅನ್ನು
ಹುಡುಕಲು ನಡೆಯುವುದರಲ್ಲಿ.

## ಇದು ಎಷ್ಟು ವೇಗವಾಗಿದೆ?

| Operation | ಇದು ಏನು ಮಾಡುತ್ತದೆ | Time |
|---|---|---|
| `add-first` | ಮುಂದೆ ಹೊಸ node | `O(1)` |
| `add-last` | ಕೊನೆಯವರೆಗೆ ನಡೆದು, ನಂತರ ಜೋಡಿಸುವುದು | `O(n)` |
| `find` | nodes ಅನ್ನು ಒಂದೊಂದಾಗಿ ಪರಿಶೀಲಿಸುವುದು | `O(n)` |
| `remove` | node ವರೆಗೆ ನಡೆದು, ನಂತರ relink ಮಾಡುವುದು | `O(n)` |
| `size` | counter ಓದುವುದು | `O(1)` |

> **Tail pointer ಬಳಸಿ ವೇಗದ add-last.** List ತನ್ನ ಕೊನೆಯ node ಅನ್ನೂ `tail` ಎಂಬ field ನಲ್ಲಿ
> ನೆನಪಿಟ್ಟುಕೊಂಡರೆ, `add-last` ಗೆ ನಡೆಯುವ ಅಗತ್ಯವಿಲ್ಲ: ಹೊಸ node ಅನ್ನು `tail` ನ ನಂತರ ಜೋಡಿಸಿ, ನಂತರ
> `tail` ಅನ್ನು ಅದಕ್ಕೆ ಸರಿಸಿ. ಇದರಿಂದ `add-last` `O(1)` ಆಗುತ್ತದೆ, queue ಕಟ್ಟುವಾಗ ಇದು ತುಂಬಾ
> ಉಪಯೋಗಕ್ಕೆ ಬರುತ್ತದೆ.

`n` nodes ಇರುವ list ಗೆ `O(n)` memory ಬೇಕು, ಮತ್ತು ಪ್ರತಿ node ತನ್ನ ಜೊತೆ ಒಂದು extra link
ಇಟ್ಟುಕೊಳ್ಳುತ್ತದೆ.

## ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು

- **Links ಅನ್ನು ತಪ್ಪು ಕ್ರಮದಲ್ಲಿ ಬದಲಿಸುವುದು.** `add-first` ನಲ್ಲಿ `node.next = head` ಗಿಂತ ಮೊದಲು
  `head = node` ಬರೆದರೆ, ಹೊಸ node ತನ್ನನ್ನೇ point ಮಾಡುತ್ತದೆ ಮತ್ತು ಉಳಿದ list ಕಳೆದುಹೋಗುತ್ತದೆ.
  ಯಾವಾಗಲೂ ಮೊದಲು ಹೊಸ node ಅನ್ನು ಜೋಡಿಸಿ, ನಂತರ ಹಳೆಯ pointer ಅನ್ನು ಸರಿಸಿ.
- **Head case ಮರೆಯುವುದು.** ಮೊದಲ node ತೆಗೆಯುವುದು ವಿಶೇಷ: ಅದರ ಹಿಂದೆ ಯಾವುದೇ `previous` node ಇಲ್ಲ,
  ಆದ್ದರಿಂದ `head` ಅನ್ನೇ ಸರಿಸಬೇಕು. ತುಂಬಾ bugs ಇಲ್ಲೇ ಅಡಗಿರುತ್ತವೆ.
- **ಕೊನೆಯನ್ನು ದಾಟಿ ಹೋಗುವುದು.** ಒಂದು node ನ `value` ಅಥವಾ `next` ಓದುವ ಮೊದಲು ಆ node `null` ಅಲ್ಲ
  ಎಂದು ಪರಿಶೀಲಿಸಿ.
- **ಎಣಿಕೆ ತಪ್ಪುವುದು.** Node ಸೇರಿಸುವ ಅಥವಾ ತೆಗೆಯುವ ಪ್ರತಿ method ನಲ್ಲೂ counter ಬದಲಿಸಿ.
- **C++ ನಲ್ಲಿ memory leaks.** `new` ನಿಂದ ಮಾಡಿದ ಪ್ರತಿ node ಅನ್ನು `delete` ನಿಂದ free ಮಾಡಬೇಕು,
  `remove` ನಲ್ಲೂ destructor ನಲ್ಲೂ. Python, Java, JavaScript ಮತ್ತು PHP ಬಳಕೆಯಾಗದ nodes ಅನ್ನು ನಿಮಗಾಗಿ
  ಸ್ವಚ್ಛಗೊಳಿಸುತ್ತವೆ.

## ಇದು ಎಲ್ಲಿ ಬಳಕೆಯಾಗುತ್ತದೆ?

- "Next" ಮತ್ತು "previous" buttons ಇರುವ **music playlists ಮತ್ತು photo galleries**. ಇವು *doubly*
  linked list ಬಳಸುತ್ತವೆ, ಅದರಲ್ಲಿ ಪ್ರತಿ node ತನ್ನ ಹಿಂದಿನ node ಕಡೆಗೂ point ಮಾಡುತ್ತದೆ.
- **Hash tables** ಒಂದೇ slot ಗೆ ಬರುವ values ಗಾಗಿ ಸಣ್ಣ linked lists ಇಟ್ಟುಕೊಳ್ಳುತ್ತವೆ.
- **Stacks ಮತ್ತು queues** ಅನ್ನು linked list ಮೇಲೆ ಕಟ್ಟಬಹುದು, ಆಗ ಅವು ಎಂದಿಗೂ ತುಂಬುವುದಿಲ್ಲ.
- **Operating systems** ನಡೆಯುತ್ತಿರುವ programs ಮತ್ತು memory ಯ ಖಾಲಿ ಭಾಗಗಳನ್ನು linked lists ನಲ್ಲಿ
  ಇಡುತ್ತವೆ.
