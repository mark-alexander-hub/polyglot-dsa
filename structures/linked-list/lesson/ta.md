**Linked list** என்பது **nodes** எனப்படும் சிறிய boxes-இன் ஒரு chain. ஒவ்வொரு node-இலும் ஒரு
value-உம் அடுத்த node-இன் address-உம் இருக்கும். List-இல் முன்னேற, **head** எனப்படும் முதல்
node-இலிருந்து தொடங்கி, அடுத்த node இல்லாத வரை links-ஐ ஒவ்வொன்றாகப் பின்தொடர்கிறீர்கள்.

## அன்றாட வாழ்க்கையில்

ஒரு train-ஐ நினைத்துப் பாருங்கள். ஒவ்வொரு coach-உம் அதற்குப் பின்னால் உள்ள coach-உடன்
இணைக்கப்பட்டிருக்கும். முன்பக்கத்தில் ஒரு coach-ஐச் சேர்க்கலாம், கடைசியில் ஒன்றைச் சேர்க்கலாம், அல்லது
நடுவில் இருந்து ஒரு coach-ஐப் பிரித்து, அதன் முன்னும் பின்னும் உள்ள coaches-ஐ ஒன்றாக இணைக்கலாம். மற்ற
coaches தங்கள் இடத்திலிருந்து நகரவே தேவையில்லை.

Treasure hunt-உம் இப்படித்தான் நடக்கிறது. முதல் clue இரண்டாவது clue எங்கே ஒளித்து
வைக்கப்பட்டிருக்கிறது என்று சொல்கிறது, இரண்டாவது clue மூன்றாவது எங்கே என்று சொல்கிறது, இப்படியே
தொடர்கிறது. நேரடியாக clue எண் 5-க்குத் தாவ முடியாது: தொடக்கத்திலிருந்து chain-ஐப் பின்தொடர வேண்டும்.

## இது எப்படி வேலை செய்கிறது

Array-இல் values memory-இன் ஒரே பகுதியில் அடுத்தடுத்து இருக்கும். Linked list வேறு மாதிரி: ஒவ்வொரு
node-உம் memory-இல் எங்கு வேண்டுமானாலும் இருக்கலாம். Nodes-ஐ இணைப்பது ஒவ்வொரு node-க்குள்ளும்
இருக்கும் `next` link தான்.

- `head` முதல் node-ஐ point செய்கிறது. List காலியாக இருந்தால், `head`-இன் value `null`.
- கடைசி node-இன் `next` `null` ஆக இருக்கும், அதாவது "chain இங்கே முடிகிறது".

(`null`-ஐ Python-இல் `None` என்றும் C++-இல் `nullptr` என்றும் சொல்வார்கள்.)

List தானே head-ஐ மட்டும் நினைவில் வைத்தால் போதும், கூடவே ஒரு counter. அதனால் முழு chain-இலும்
நடக்காமலேயே தன் size-ஐச் சொல்ல முடியும்.

Linked list-ஐயும் array-ஐயும் இப்படி ஒப்பிடலாம்:

| | Array | Linked list |
|---|---|---|
| Values எங்கே இருக்கின்றன | memory-இல் அடுத்தடுத்து | எங்கு வேண்டுமானாலும், links மூலம் இணைப்பு |
| Index 5-இல் உள்ள value-ஐ எடுப்பது | நேரடியாக அங்கே தாவுவது, `O(1)` | head-இலிருந்து நடந்து போவது, `O(n)` |
| முன்பக்கத்தில் ஒரு value சேர்ப்பது | ஒவ்வொரு value-ஐயும் வலப்பக்கம் நகர்த்துவது, `O(n)` | இரண்டு links-ஐ மாற்றுவது, `O(1)` |
| Extra memory | எதுவும் இல்லை | ஒவ்வொரு node-இலும் ஒரு link |

## Operations

### add-first: முன்பக்கத்தில் ஒரு புதிய node வைப்பது

1. Value-க்காக ஒரு புதிய node உருவாக்குங்கள்.
2. புதிய node-இன் `next`-ஐ இப்போதைய head-ஐ point செய்ய வையுங்கள்.
3. `head`-ஐப் புதிய node-க்கு நகர்த்துங்கள்.

வரிசை முறை முக்கியம். முதலில் `head`-ஐ நகர்த்தினால், பழைய முதல் node-இன் address தொலைந்துவிடும்,
அதோடு மீதமுள்ள முழு list-உம் தொலைந்துவிடும்.

<!-- code: add-first -->

### add-last: கடைசியில் ஒரு புதிய node வைப்பது

1. Value-க்காக ஒரு புதிய node உருவாக்குங்கள்.
2. List காலியாக இருந்தால், புதிய node-ஏ head ஆகிவிடும், வேலை முடிந்தது.
3. இல்லையென்றால், head-இலிருந்து தொடங்கி, `next` `null` ஆக உள்ள node கிடைக்கும் வரை `next`-ஐப்
   பின்தொடருங்கள். அதுதான் கடைசி node.
4. கடைசி node-இன் `next`-ஐப் புதிய node-ஐ point செய்ய வையுங்கள்.

<!-- code: add-last -->

### find: இந்த value list-இல் இருக்கிறதா?

Head-இலிருந்து தொடங்கி, ஒவ்வொரு node-ஐயும் ஒன்றன் பின் ஒன்றாகச் சரிபாருங்கள். ஏதாவது ஒரு node-இல்
அந்த value இருந்தால், பதில் ஆம். கடைசி node-ஐத் தாண்டி `null`-ஐ அடைந்தால், பதில் இல்லை.

<!-- code: find -->

### remove: ஒரு value உள்ள முதல் node-ஐ நீக்குவது

1. List காலியாக இருந்தால் நீக்குவதற்கு எதுவும் இல்லை, அதனால் error கொடுத்து நிறுத்துங்கள்.
2. Head-இலேயே அந்த value இருந்தால், `head`-ஐ இரண்டாவது node-க்கு நகர்த்துங்கள். பழைய முதல் node
   இப்போது chain-இன் பகுதி இல்லை.
3. இல்லையென்றால், `previous.next`-இல் அந்த value கிடைக்கும் வரை `previous` என்ற pointer-உடன்
   நடங்கள். அதற்கு முன்பே கடைசியை அடைந்துவிட்டால், value list-இல் இல்லை: error கொடுத்து
   நிறுத்துங்கள்.
4. `previous.next`-ஐ அந்த node-ஐத் தாண்டி, அதற்கு அடுத்த node-ஐ point செய்ய வையுங்கள். இப்போது chain
   அந்த node-ஐத் தவிர்த்துச் செல்கிறது.

<!-- code: remove -->

Step 4-இல் உள்ள relinking ஒரே ஒரு line, அது `O(1)` எடுக்கும். நேரம் எடுப்பது அந்த node-ஐத் தேடி
நடப்பதுதான்.

## இது எவ்வளவு வேகமானது?

| Operation | இது என்ன செய்கிறது | Time |
|---|---|---|
| `add-first` | முன்பக்கத்தில் புதிய node | `O(1)` |
| `add-last` | கடைசி வரை நடந்து, பிறகு இணைப்பது | `O(n)` |
| `find` | nodes-ஐ ஒவ்வொன்றாகச் சரிபார்ப்பது | `O(n)` |
| `remove` | node வரை நடந்து, பிறகு relink செய்வது | `O(n)` |
| `size` | counter-ஐப் படிப்பது | `O(1)` |

> **Tail pointer மூலம் வேகமான add-last.** List தன் கடைசி node-ஐயும் `tail` என்ற field-இல் நினைவில்
> வைத்தால், `add-last`-க்கு நடக்கத் தேவையில்லை: புதிய node-ஐ `tail`-க்குப் பின் இணைத்து, பிறகு
> `tail`-ஐ அதற்கு நகர்த்துங்கள். இதனால் `add-last` `O(1)` ஆகிறது; queue கட்டும்போது இது மிகவும்
> பயன்படும்.

`n` nodes உள்ள list-க்கு `O(n)` memory தேவை, ஒவ்வொரு node-உம் கூடுதலாக ஒரு link-ஐ வைத்திருக்கும்.

## பொதுவான தவறுகள்

- **Links-ஐத் தவறான வரிசை முறையில் மாற்றுவது.** `add-first`-இல் `node.next = head`-க்கு முன்பே
  `head = node` என்று எழுதினால், புதிய node தன்னையே point செய்யும், மீதமுள்ள list தொலைந்துவிடும்.
  எப்போதும் முதலில் புதிய node-ஐ இணையுங்கள், பிறகு பழைய pointer-ஐ நகர்த்துங்கள்.
- **Head case-ஐ மறப்பது.** முதல் node-ஐ நீக்குவது தனி: அதற்கு முன் `previous` node எதுவும் இல்லை,
  அதனால் `head`-ஐயே நகர்த்த வேண்டும். பல bugs இங்கேதான் ஒளிந்திருக்கும்.
- **கடைசியைத் தாண்டிப் போவது.** ஒரு node-இன் `value`-ஐயோ `next`-ஐயோ படிக்கும் முன், அந்த node
  `null` இல்லை என்று சரிபாருங்கள்.
- **எண்ணிக்கையைத் தவறவிடுவது.** Node-ஐச் சேர்க்கும் அல்லது நீக்கும் ஒவ்வொரு method-இலும்
  counter-ஐ மாற்றுங்கள்.
- **C++-இல் memory leaks.** `new` மூலம் உருவான ஒவ்வொரு node-ஐயும் `delete` மூலம் free செய்ய
  வேண்டும், `remove`-இலும் destructor-இலும். Python, Java, JavaScript, PHP பயன்படாத nodes-ஐ உங்களுக்காகச்
  சுத்தம் செய்துவிடும்.

## இது எங்கே பயன்படுகிறது?

- "Next", "previous" buttons உள்ள **music playlists, photo galleries**. இவை *doubly* linked
  list-ஐப் பயன்படுத்துகின்றன; அதில் ஒவ்வொரு node-உம் தனக்கு முந்தைய node-ஐயும் point செய்யும்.
- **Hash tables** ஒரே slot-க்கு வரும் values-க்காகச் சிறிய linked lists-ஐ வைத்திருக்கும்.
- **Stacks, queues** ஆகியவற்றை linked list மேல் கட்டலாம், அப்போது அவை ஒருபோதும் நிரம்பாது.
- **Operating systems** இயங்கும் programs-ஐயும் memory-இன் காலிப் பகுதிகளையும் linked lists-இல்
  வைக்கின்றன.
