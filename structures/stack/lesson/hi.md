**Stack** एक ऐसी list है जिसमें आप चीज़ें सिर्फ़ एक ही सिरे से जोड़ या हटा सकते हैं। उस
सिरे को **top** कहते हैं। जो चीज़ आपने सबसे आख़िर में रखी, वही सबसे पहले बाहर आती है।
इसे **LIFO** कहते हैं: *Last In, First Out*, यानी जो आख़िर में आया, वो सबसे पहले जाएगा।

## असल ज़िंदगी में

शादी के buffet में रखी प्लेटों के बारे में सोचिए। साफ़ प्लेटें ढेर के ऊपर रखी जाती हैं, और हर
मेहमान ऊपर से ही प्लेट उठाता है। कोई भी बीच से या नीचे से प्लेट नहीं खींचता। जो प्लेट सबसे
आख़िर में रखी गई, वही सबसे पहले उठाई जाती है।

आप बिना ध्यान दिए रोज़ stack इस्तेमाल करते हैं:

- Text editor में **Undo** सबसे पहले आपका सबसे नया बदलाव हटाता है।
- Browser का **back button** आपको उस page पर ले जाता है जो आपने सबसे आख़िर में खोला था।
- मेज़ पर रखी **कॉपियों का ढेर**: आप वही कॉपी उठाते हैं जो सबसे आख़िर में रखी थी।

## ये काम कैसे करता है

हम stack को एक array पर बनाएँगे जिसमें boxes की गिनती तय है। इस गिनती को **capacity**
कहते हैं। हम एक number रखते हैं, `top`, जो top वाली value का index है।

- जब stack खाली होता है, तो `top` की value `-1` होती है, क्योंकि अभी कोई top value है ही नहीं।
- जब stack भरा हुआ होता है, तो `top` की value `capacity - 1` होती है, यानी आख़िरी box।

## Operations

Stack के तीन मुख्य operations हैं। तीनों सिर्फ़ top को ही देखते हैं।

### push: top पर एक value रखना

1. अगर `top` पहले से आख़िरी box पर है, तो stack भरा हुआ है। उसमें और जोड़ने को
   **overflow** कहते हैं, इसलिए हम error देकर रुक जाते हैं।
2. नहीं तो, `top` को एक ऊपर खिसकाइए।
3. Value को `top` वाले box में रख दीजिए।

<!-- code: push -->

### pop: top वाली value निकालना

1. अगर `top` की value `-1` है, तो stack खाली है। खाली stack से निकालने को **underflow**
   कहते हैं, इसलिए हम error देकर रुक जाते हैं।
2. `top` वाली value याद रखिए।
3. `top` को एक नीचे खिसकाइए, और याद रखी हुई value लौटा दीजिए।

<!-- code: pop -->

ध्यान दीजिए कि हम पुरानी value को **मिटाते नहीं** हैं। `top` को नीचे खिसकाना काफ़ी है: वो box
अब stack के बाहर है, और अगला `push` उस पर नई value लिख देगा। ऊपर वाले playground में ये
पुरानी values हल्के रंग में दिखती हैं।

### peek: top को बिना हटाए देखना

`peek` बस `top` वाली value लौटाता है और कुछ नहीं बदलता। ये तब काम आता है जब आपको कुछ तय करने
से पहले देखना हो कि top पर क्या है।

## ये कितना तेज़ है?

हर operation सिर्फ़ top वाले box को छूता है, stack में चाहे जितनी values हों। इसलिए सबमें
बराबर और बहुत कम समय लगता है, जिसे `O(1)` (constant time) लिखते हैं।

| Operation | ये क्या करता है | Time |
|---|---|---|
| `push` | top पर value रखना | `O(1)` |
| `pop` | top वाली value निकालना | `O(1)` |
| `peek` | top वाली value देखना | `O(1)` |
| `isEmpty` | देखना कि `top` की value `-1` है या नहीं | `O(1)` |
| कोई value ढूँढना | मिलने तक values एक-एक करके pop करना | `O(n)` |

`n` values की जगह वाला stack `n` boxes इस्तेमाल करता है, इसलिए उसे `O(n)` memory चाहिए।

## आम गलतियाँ

- **बिना जाँचे pop करना।** `pop` या `peek` से पहले `isEmpty()` जाँचिए (या error पकड़िए)।
  Underflow stack का सबसे आम bug है।
- **सिरे उलट देना।** Top वो सिरा है जहाँ आख़िरी value गई थी। अगर आपका `pop` *सबसे पहले* push
  की गई value लौटाता है, तो आपने गलती से queue बना दी है।
- **"भरा हुआ" में एक का फ़र्क।** आख़िरी box का index `capacity - 1` है, `capacity` नहीं।
- **ये भूल जाना कि क्रम उलट जाता है।** `1, 2, 3` push करके तीन बार pop कीजिए: आपको `3, 2, 1`
  मिलेगा। Stack क्रम को उलट देता है।

## ये कहाँ काम आता है?

- **Function calls।** जब एक function दूसरे function को call करता है, तो computer अधूरा काम
  *call stack* पर push कर देता है, और अंदर वाला function ख़त्म होने पर उसे pop करता है। जो
  function खुद को हमेशा call करता रहे, उसकी जगह ख़त्म हो जाती है: यही असली **stack overflow** है।
- **Undo और back buttons**, जैसा ऊपर देखा।
- Code में **brackets जाँचना**: हर `(` push होता है, और हर `)` अपने जोड़ीदार को pop करता है।
- किसी शब्द या list को **उल्टा करना**।
- Graphs और mazes में **depth-first search**, जो आप आगे सीखेंगे।

## ये करके देखिए

1. `4, 8, 15` push कीजिए, फिर एक बार pop कीजिए। अब top पर क्या है? अपना जवाब playground में
   जाँचिए।
2. Stack से `STACK` शब्द को उल्टा कीजिए: हर अक्षर push कीजिए, फिर सबको pop कीजिए।
3. एक function लिखिए जो जाँचे कि `"(()())"` में brackets balanced हैं या नहीं। फिर `"(()"` के
   साथ आज़माइए।
4. Program को ऐसे बदलिए कि भरे हुए stack पर `push` करने से error की जगह capacity दोगुनी हो
   जाए। Python lists और C++ vectors ऐसे ही बढ़ते हैं।
