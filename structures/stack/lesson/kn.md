**Stack** ಎಂದರೆ ಒಂದೇ ತುದಿಯಿಂದ ಮಾತ್ರ ವಸ್ತುಗಳನ್ನು ಸೇರಿಸಲು ಅಥವಾ ತೆಗೆಯಲು ಸಾಧ್ಯವಿರುವ ಒಂದು list. ಆ
ತುದಿಯನ್ನು **top** ಎನ್ನುತ್ತಾರೆ. ನೀವು ಕೊನೆಗೆ ಇಟ್ಟದ್ದು ಮೊದಲು ಹೊರಗೆ ಬರುತ್ತದೆ. ಇದನ್ನು **LIFO**
ಎನ್ನುತ್ತಾರೆ: *Last In, First Out*, ಅಂದರೆ ಕೊನೆಗೆ ಬಂದದ್ದು ಮೊದಲು ಹೋಗುತ್ತದೆ.

## ನಿಜ ಜೀವನದಲ್ಲಿ

ಮದುವೆಯ buffet ನಲ್ಲಿ ಇಟ್ಟಿರುವ ತಟ್ಟೆಗಳ ಬಗ್ಗೆ ಯೋಚಿಸಿ. ಸ್ವಚ್ಛ ತಟ್ಟೆಗಳನ್ನು ರಾಶಿಯ ಮೇಲೆ ಇಡುತ್ತಾರೆ,
ಮತ್ತು ಪ್ರತಿ ಅತಿಥಿಯೂ ಮೇಲಿನಿಂದಲೇ ತಟ್ಟೆ ತೆಗೆದುಕೊಳ್ಳುತ್ತಾರೆ. ಯಾರೂ ಮಧ್ಯದಿಂದ ಅಥವಾ ಕೆಳಗಿನಿಂದ ತಟ್ಟೆ
ಎಳೆಯುವುದಿಲ್ಲ. ಕೊನೆಗೆ ಇಟ್ಟ ತಟ್ಟೆಯನ್ನೇ ಮೊದಲು ತೆಗೆದುಕೊಳ್ಳಲಾಗುತ್ತದೆ.

ಗಮನಿಸದೆಯೇ ನೀವು ಪ್ರತಿದಿನ stack ಬಳಸುತ್ತೀರಿ:

- Text editor ನಲ್ಲಿ **Undo** ನಿಮ್ಮ ಇತ್ತೀಚಿನ ಬದಲಾವಣೆಯನ್ನು ಮೊದಲು ತೆಗೆದುಹಾಕುತ್ತದೆ.
- Browser ನ **back button** ನೀವು ಕೊನೆಗೆ ತೆರೆದ page ಗೆ ನಿಮ್ಮನ್ನು ಕರೆದೊಯ್ಯುತ್ತದೆ.
- ಮೇಜಿನ ಮೇಲಿನ **ನೋಟ್‌ಬುಕ್‌ಗಳ ರಾಶಿ**: ನೀವು ಕೊನೆಗೆ ಇಟ್ಟ ನೋಟ್‌ಬುಕ್ ಅನ್ನೇ ಮೊದಲು ಎತ್ತಿಕೊಳ್ಳುತ್ತೀರಿ.

## ಇದು ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ

ನಾವು stack ಅನ್ನು ನಿಗದಿತ ಸಂಖ್ಯೆಯ boxes ಇರುವ ಒಂದು array ಮೇಲೆ ಕಟ್ಟುತ್ತೇವೆ. ಆ ಸಂಖ್ಯೆಯನ್ನು
**capacity** ಎನ್ನುತ್ತಾರೆ. ನಾವು `top` ಎಂಬ ಒಂದು number ಇಡುತ್ತೇವೆ, ಅದು top ನಲ್ಲಿರುವ value ನ index.

- Stack ಖಾಲಿ ಇದ್ದಾಗ `top` ನ value `-1`, ಏಕೆಂದರೆ ಇನ್ನೂ ಯಾವುದೇ top value ಇಲ್ಲ.
- Stack ತುಂಬಿದಾಗ `top` ನ value `capacity - 1`, ಅಂದರೆ ಕೊನೆಯ box.

> **ನಾವೇ ಏಕೆ ಕಟ್ಟಬೇಕು?** ಪ್ರತಿ ಭಾಷೆಯಲ್ಲೂ ಈಗಾಗಲೇ ಸಿದ್ಧವಾದ stack ಇದೆ: Python ನಲ್ಲಿ `list`,
> C++ ನಲ್ಲಿ `std::stack`, Java ದಲ್ಲಿ `ArrayDeque`, JavaScript ನಲ್ಲಿ array. ಒಮ್ಮೆ ನೀವೇ ಕಟ್ಟಿದರೆ ಆ
> tools ನಿಮಗಾಗಿ ಏನು ಮಾಡುತ್ತವೆ ಎಂದು ಅರ್ಥವಾಗುತ್ತದೆ, ಮತ್ತು interview ಗಳಲ್ಲಿ ಈ ಪ್ರಶ್ನೆ ತುಂಬಾ
> ಕೇಳುತ್ತಾರೆ.

## Operations

Stack ಗೆ ಮೂರು ಮುಖ್ಯ operations ಇವೆ. ಮೂರೂ top ಅನ್ನು ಮಾತ್ರ ನೋಡುತ್ತವೆ.

### push: top ಮೇಲೆ ಒಂದು value ಇಡುವುದು

1. `top` ಈಗಾಗಲೇ ಕೊನೆಯ box ನಲ್ಲಿದ್ದರೆ stack ತುಂಬಿದೆ. ಇನ್ನಷ್ಟು ಸೇರಿಸುವುದನ್ನು **overflow**
   ಎನ್ನುತ್ತಾರೆ, ಆದ್ದರಿಂದ ನಾವು error ಕೊಟ್ಟು ನಿಲ್ಲಿಸುತ್ತೇವೆ.
2. ಇಲ್ಲದಿದ್ದರೆ, `top` ಅನ್ನು ಒಂದು ಮೇಲೆ ಸರಿಸಿ.
3. Value ಅನ್ನು `top` ನಲ್ಲಿರುವ box ನಲ್ಲಿ ಇಡಿ.

<!-- code: push -->

### pop: top ನಲ್ಲಿರುವ value ತೆಗೆಯುವುದು

1. `top` ನ value `-1` ಆಗಿದ್ದರೆ stack ಖಾಲಿ ಇದೆ. ಖಾಲಿ stack ನಿಂದ ತೆಗೆಯುವುದನ್ನು **underflow**
   ಎನ್ನುತ್ತಾರೆ, ಆದ್ದರಿಂದ ನಾವು error ಕೊಟ್ಟು ನಿಲ್ಲಿಸುತ್ತೇವೆ.
2. `top` ನಲ್ಲಿರುವ value ಅನ್ನು ನೆನಪಿಟ್ಟುಕೊಳ್ಳಿ.
3. `top` ಅನ್ನು ಒಂದು ಕೆಳಗೆ ಸರಿಸಿ, ನೆನಪಿಟ್ಟ value ಅನ್ನು return ಮಾಡಿ.

<!-- code: pop -->

ಗಮನಿಸಿ, ನಾವು ಹಳೆಯ value ಅನ್ನು **ಅಳಿಸುವುದಿಲ್ಲ**. `top` ಅನ್ನು ಕೆಳಗೆ ಸರಿಸಿದರೆ ಸಾಕು: ಆ box ಈಗ stack
ನ ಹೊರಗಿದೆ, ಮುಂದಿನ `push` ಅದರ ಮೇಲೆ ಹೊಸ value ಬರೆಯುತ್ತದೆ. ಮೇಲಿನ playground ನಲ್ಲಿ ಈ ಹಳೆಯ values
ಮಸುಕಾಗಿ ಕಾಣುತ್ತವೆ.

### peek: top ಅನ್ನು ತೆಗೆಯದೆ ನೋಡುವುದು

`peek` ಕೇವಲ `top` ನಲ್ಲಿರುವ value ಅನ್ನು return ಮಾಡುತ್ತದೆ, ಏನನ್ನೂ ಬದಲಿಸುವುದಿಲ್ಲ. ಏನು ಮಾಡಬೇಕೆಂದು
ನಿರ್ಧರಿಸುವ ಮೊದಲು top ನಲ್ಲಿ ಏನಿದೆ ಎಂದು ನೋಡಬೇಕಾದಾಗ ಇದು ಉಪಯೋಗಕ್ಕೆ ಬರುತ್ತದೆ.

## ಇದು ಎಷ್ಟು ವೇಗವಾಗಿದೆ?

Stack ನಲ್ಲಿ ಎಷ್ಟೇ values ಇದ್ದರೂ, ಪ್ರತಿ operation top box ಅನ್ನು ಮಾತ್ರ ಮುಟ್ಟುತ್ತದೆ. ಆದ್ದರಿಂದ ಎಲ್ಲಕ್ಕೂ
ಒಂದೇ ರೀತಿಯ ಕಡಿಮೆ ಸಮಯ ಸಾಕು, ಇದನ್ನು `O(1)` (constant time) ಎಂದು ಬರೆಯುತ್ತಾರೆ.

| Operation | ಇದು ಏನು ಮಾಡುತ್ತದೆ | Time |
|---|---|---|
| `push` | top ಮೇಲೆ value ಇಡುವುದು | `O(1)` |
| `pop` | top value ತೆಗೆಯುವುದು | `O(1)` |
| `peek` | top value ನೋಡುವುದು | `O(1)` |
| `isEmpty` | `top` ನ value `-1` ಹೌದೇ ಎಂದು ನೋಡುವುದು | `O(1)` |
| ಒಂದು value ಹುಡುಕುವುದು | ಸಿಗುವವರೆಗೂ values ಅನ್ನು ಒಂದೊಂದಾಗಿ pop ಮಾಡುವುದು | `O(n)` |

`n` values ಗೆ ಜಾಗ ಇರುವ stack `n` boxes ಬಳಸುತ್ತದೆ, ಆದ್ದರಿಂದ ಅದಕ್ಕೆ `O(n)` memory ಬೇಕು.

## ಸಾಮಾನ್ಯ ತಪ್ಪುಗಳು

- **ಪರಿಶೀಲಿಸದೆ pop ಮಾಡುವುದು.** `pop` ಅಥವಾ `peek` ಮೊದಲು `isEmpty()` ಪರಿಶೀಲಿಸಿ (ಅಥವಾ error
  ಹಿಡಿಯಿರಿ). Underflow stack ನ ಅತಿ ಸಾಮಾನ್ಯ bug.
- **ತುದಿಗಳನ್ನು ಅದಲುಬದಲು ಮಾಡುವುದು.** ಕೊನೆಯ value ಹೋದ ತುದಿಯೇ top. ನಿಮ್ಮ `pop` *ಮೊದಲು* push
  ಮಾಡಿದ value ಅನ್ನು return ಮಾಡಿದರೆ, ನೀವು ತಿಳಿಯದೆ queue ಕಟ್ಟಿದ್ದೀರಿ.
- **"ತುಂಬಿದೆ" ಎಂಬಲ್ಲಿ ಒಂದರ ವ್ಯತ್ಯಾಸ.** ಕೊನೆಯ box ನ index `capacity - 1`, `capacity` ಅಲ್ಲ.
- **ಕ್ರಮ ತಿರುಗುತ್ತದೆ ಎಂಬುದನ್ನು ಮರೆಯುವುದು.** `1, 2, 3` push ಮಾಡಿ ಮೂರು ಬಾರಿ pop ಮಾಡಿ: ನಿಮಗೆ
  `3, 2, 1` ಸಿಗುತ್ತದೆ. Stack ಕ್ರಮವನ್ನು ತಿರುಗಿಸುತ್ತದೆ.

## ಇದು ಎಲ್ಲಿ ಬಳಕೆಯಾಗುತ್ತದೆ?

- **Function calls.** ಒಂದು function ಇನ್ನೊಂದನ್ನು call ಮಾಡಿದಾಗ, computer ಅರ್ಧ ಮುಗಿದ ಕೆಲಸವನ್ನು
  *call stack* ಮೇಲೆ push ಮಾಡುತ್ತದೆ, ಒಳಗಿನ function ಮುಗಿದಾಗ ಅದನ್ನು pop ಮಾಡುತ್ತದೆ. ತನ್ನನ್ನು ತಾನೇ
  ಎಂದೆಂದಿಗೂ call ಮಾಡುವ function ಗೆ ಜಾಗ ಮುಗಿದುಹೋಗುತ್ತದೆ: ಅದೇ ನಿಜವಾದ **stack overflow**.
- **Undo ಮತ್ತು back buttons**, ಮೇಲೆ ನೋಡಿದಂತೆ.
- Code ನಲ್ಲಿ **brackets ಪರಿಶೀಲಿಸುವುದು**: ಪ್ರತಿ `(` push ಆಗುತ್ತದೆ, ಪ್ರತಿ `)` ತನ್ನ ಜೋಡಿಯನ್ನು pop
  ಮಾಡುತ್ತದೆ.
- ಒಂದು ಪದ ಅಥವಾ list ಅನ್ನು **ತಿರುಗಿಸುವುದು**.
- Graphs ಮತ್ತು mazes ನಲ್ಲಿ **depth-first search**, ಇದನ್ನು ನೀವು ಮುಂದೆ ಕಲಿಯುತ್ತೀರಿ.

## ಇವುಗಳನ್ನು ಮಾಡಿ ನೋಡಿ

1. `4, 8, 15` push ಮಾಡಿ, ನಂತರ ಒಮ್ಮೆ pop ಮಾಡಿ. ಈಗ top ನಲ್ಲಿ ಏನಿದೆ? ನಿಮ್ಮ ಉತ್ತರವನ್ನು playground
   ನಲ್ಲಿ ಪರಿಶೀಲಿಸಿ.
2. Stack ಬಳಸಿ `STACK` ಪದವನ್ನು ತಿರುಗಿಸಿ: ಪ್ರತಿ ಅಕ್ಷರವನ್ನು push ಮಾಡಿ, ನಂತರ ಎಲ್ಲವನ್ನೂ pop ಮಾಡಿ.
3. `"(()())"` ನಲ್ಲಿರುವ brackets balanced ಆಗಿವೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸುವ ಒಂದು function ಬರೆಯಿರಿ. ನಂತರ
   `"(()"` ಜೊತೆ ಪ್ರಯತ್ನಿಸಿ.
4. ತುಂಬಿದ stack ಮೇಲೆ `push` ಮಾಡಿದಾಗ error ಬದಲು capacity ಎರಡರಷ್ಟು ಆಗುವಂತೆ program ಬದಲಿಸಿ. Python
   lists ಮತ್ತು C++ vectors ಹೀಗೆಯೇ ಬೆಳೆಯುತ್ತವೆ.
