**Stack** என்பது ஒரே ஒரு முனையில் மட்டும் பொருட்களைச் சேர்க்கவோ நீக்கவோ முடிகிற ஒரு list.
அந்த முனைக்கு **top** என்று பெயர். நீங்கள் கடைசியாக வைத்தது தான் முதலில் வெளியே வரும். இதை
**LIFO** என்பார்கள்: *Last In, First Out*, அதாவது கடைசியாக வந்தது முதலில் போகும்.

## அன்றாட வாழ்க்கையில்

கல்யாண buffet-இல் அடுக்கி வைத்திருக்கும் தட்டுகளை நினைத்துப் பாருங்கள். சுத்தமான தட்டுகள்
அடுக்கின் மேலே வைக்கப்படுகின்றன, ஒவ்வொரு விருந்தினரும் மேலிருந்தே தட்டை எடுக்கிறார்கள். யாரும்
நடுவிலிருந்தோ அடியிலிருந்தோ தட்டை இழுப்பதில்லை. கடைசியாக வைத்த தட்டு தான் முதலில்
எடுக்கப்படுகிறது.

கவனிக்காமலேயே நீங்கள் தினமும் stack பயன்படுத்துகிறீர்கள்:

- Text editor-இல் **Undo** உங்கள் கடைசி மாற்றத்தை முதலில் நீக்குகிறது.
- Browser-இன் **back button** நீங்கள் கடைசியாகத் திறந்த page-க்கு உங்களைக் கொண்டு செல்கிறது.
- மேசையில் அடுக்கிய **நோட்டுப் புத்தகங்கள்**: கடைசியாக வைத்ததைத் தான் முதலில் எடுப்பீர்கள்.

## இது எப்படி வேலை செய்கிறது

நிலையான எண்ணிக்கையில் boxes உள்ள ஒரு array மேல் stack-ஐ உருவாக்கப் போகிறோம். அந்த
எண்ணிக்கைக்கு **capacity** என்று பெயர். `top` என்ற ஒரு number-ஐ வைத்துக்கொள்கிறோம், அது top-இல்
உள்ள value-இன் index.

- Stack காலியாக இருக்கும்போது `top`-இன் value `-1`, ஏனென்றால் இன்னும் top value எதுவும் இல்லை.
- Stack நிரம்பியிருக்கும்போது `top`-இன் value `capacity - 1`, அதாவது கடைசி box.

> **நாமே ஏன் உருவாக்க வேண்டும்?** ஒவ்வொரு மொழியிலும் ஏற்கனவே தயாரான stack உள்ளது: Python-இல்
> `list`, C++-இல் `std::stack`, Java-வில் `ArrayDeque`, JavaScript-இல் array, PHP-இல் `SplStack`. ஒருமுறை நீங்களே
> உருவாக்கினால் அந்த tools உங்களுக்காக என்ன செய்கின்றன என்று புரியும், interview-களிலும் இந்தக்
> கேள்வியை அடிக்கடி கேட்பார்கள்.

## Operations

Stack-க்கு மூன்று முக்கிய operations உள்ளன. மூன்றும் top-ஐ மட்டுமே பார்க்கின்றன.

### push: top-இல் ஒரு value வைப்பது

1. `top` ஏற்கனவே கடைசி box-இல் இருந்தால், stack நிரம்பியது. மேலும் சேர்ப்பதை **overflow**
   என்பார்கள், அதனால் error கொடுத்து நிறுத்துகிறோம்.
2. இல்லையென்றால், `top`-ஐ ஒன்று மேலே நகர்த்துங்கள்.
3. Value-ஐ `top`-இல் உள்ள box-இல் வையுங்கள்.

<!-- code: push -->

### pop: top value-ஐ எடுப்பது

1. `top`-இன் value `-1` என்றால், stack காலியாக உள்ளது. காலியான stack-இலிருந்து எடுப்பதை
   **underflow** என்பார்கள், அதனால் error கொடுத்து நிறுத்துகிறோம்.
2. `top`-இல் உள்ள value-ஐ நினைவில் வைத்துக்கொள்ளுங்கள்.
3. `top`-ஐ ஒன்று கீழே நகர்த்தி, நினைவில் வைத்த value-ஐ return செய்யுங்கள்.

<!-- code: pop -->

கவனியுங்கள், பழைய value-ஐ நாம் **அழிப்பதில்லை**. `top`-ஐக் கீழே நகர்த்தினால் போதும்: அந்த box
இப்போது stack-க்கு வெளியே உள்ளது, அடுத்த `push` அதன் மேல் புதிய value-ஐ எழுதும். மேலே உள்ள
playground-இல் இந்தப் பழைய values மங்கலாகத் தெரியும்.

### peek: top-ஐ நீக்காமல் பார்ப்பது

`peek` வெறுமனே `top`-இல் உள்ள value-ஐ return செய்கிறது, எதையும் மாற்றுவதில்லை. என்ன செய்வது
என்று முடிவெடுப்பதற்கு முன் top-இல் என்ன இருக்கிறது என்று பார்க்க வேண்டியிருக்கும்போது இது
உதவும்.

## இது எவ்வளவு வேகமானது?

Stack-இல் எத்தனை values இருந்தாலும், ஒவ்வொரு operation-உம் top box-ஐ மட்டுமே தொடுகிறது. அதனால்
எல்லாவற்றுக்கும் ஒரே அளவு குறைந்த நேரம் தான் ஆகும், இதை `O(1)` (constant time) என்று எழுதுவார்கள்.

| Operation | இது என்ன செய்கிறது | Time |
|---|---|---|
| `push` | top-இல் value வைப்பது | `O(1)` |
| `pop` | top value-ஐ எடுப்பது | `O(1)` |
| `peek` | top value-ஐப் பார்ப்பது | `O(1)` |
| `isEmpty` | `top`-இன் value `-1` தானா என்று பார்ப்பது | `O(1)` |
| ஒரு value-ஐத் தேடுவது | கிடைக்கும் வரை values-ஐ ஒவ்வொன்றாக pop செய்வது | `O(n)` |

`n` values-க்கு இடம் உள்ள stack `n` boxes பயன்படுத்துகிறது, அதனால் அதற்கு `O(n)` memory தேவை.

## பொதுவான தவறுகள்

- **சரிபார்க்காமல் pop செய்வது.** `pop` அல்லது `peek`-க்கு முன் `isEmpty()` சரிபாருங்கள் (அல்லது
  error-ஐப் பிடியுங்கள்). Underflow தான் stack-இன் மிகப் பொதுவான bug.
- **முனைகளை மாற்றிக் குழப்புவது.** கடைசி value போன முனை தான் top. உங்கள் `pop` *முதலில்* push
  செய்த value-ஐ return செய்தால், நீங்கள் தெரியாமல் queue உருவாக்கிவிட்டீர்கள்.
- **"நிரம்பியது" என்பதில் ஒன்று வித்தியாசம்.** கடைசி box-இன் index `capacity - 1`, `capacity` அல்ல.
- **வரிசை முறை தலைகீழாகும் என்பதை மறப்பது.** `1, 2, 3` push செய்து மூன்று முறை pop செய்யுங்கள்:
  `3, 2, 1` கிடைக்கும். Stack வரிசை முறையைத் தலைகீழாக்குகிறது.

## இது எங்கே பயன்படுகிறது?

- **Function calls.** ஒரு function இன்னொன்றை call செய்யும்போது, computer பாதியில் நிற்கும் வேலையை
  *call stack*-இல் push செய்கிறது, உள்ளே உள்ள function முடிந்ததும் அதை pop செய்கிறது. தன்னையே
  முடிவில்லாமல் call செய்யும் function-க்கு இடம் தீர்ந்துவிடும்: அது தான் உண்மையான **stack overflow**.
- **Undo மற்றும் back buttons**, மேலே பார்த்தது போல.
- Code-இல் **brackets சரிபார்ப்பது**: ஒவ்வொரு `(`-உம் push ஆகும், ஒவ்வொரு `)`-உம் தன் ஜோடியை pop
  செய்யும்.
- ஒரு சொல்லையோ list-ஐயோ **தலைகீழாக்குவது**.
- Graphs மற்றும் mazes-இல் **depth-first search**, இதைப் பின்னர் கற்றுக்கொள்வீர்கள்.

## இவற்றைச் செய்து பாருங்கள்

1. `4, 8, 15` push செய்து, பிறகு ஒருமுறை pop செய்யுங்கள். இப்போது top-இல் என்ன உள்ளது? உங்கள்
   பதிலை playground-இல் சரிபாருங்கள்.
2. Stack பயன்படுத்தி `STACK` என்ற சொல்லைத் தலைகீழாக்குங்கள்: ஒவ்வொரு எழுத்தையும் push செய்து,
   பிறகு எல்லாவற்றையும் pop செய்யுங்கள்.
3. `"(()())"`-இல் உள்ள brackets balanced-ஆக உள்ளனவா என்று சரிபார்க்கும் ஒரு function எழுதுங்கள்.
   பிறகு `"(()"` உடன் முயன்று பாருங்கள்.
4. நிரம்பிய stack-இல் `push` செய்யும்போது error-க்குப் பதிலாக capacity இரண்டு மடங்காகும்படி
   program-ஐ மாற்றுங்கள். Python lists மற்றும் C++ vectors இப்படித்தான் வளர்கின்றன.
